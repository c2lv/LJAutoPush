### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
req = [int(x) for x in data[1:1 + n]]
m = int(data[1 + n])
if sum(req) <= m:
    print(max(req))
else:
    lo, hi = 0, max(req)
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if sum(mid if r > mid else r for r in req) <= m:
            lo = mid
        else:
            hi = mid - 1
    print(lo)
```
