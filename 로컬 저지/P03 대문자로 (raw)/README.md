# [P03] 대문자로 (raw)

[문제 보기](https://localjudge.com/problems/P03)

> 프롬프트를 두 칸에 나눠 쓰는 것이 어떻게 맞물리는지 익히는 문제입니다. 받은 글을 대문자로 바꿔보세요.

## 분류

100점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 아주 쉬움, 출력 형식, 변환, 한 줄 입력, 한국어

## 문제

영어 소문자 단어 하나가 들어옵니다. 전부 대문자로 바꿔 출력해야 합니다.

| 들어오는 줄 | 내야 하는 답 |
| --- | --- |
| `hello` | `HELLO` |

바꾸는 일 자체는 쉽습니다. 이 문제가 익히게 하려는 것은 두 칸에 나눠 쓴 글이 입력과 어떻게 맞물리는지입니다. raw 모드라서 채팅 템플릿이 없고, 세 덩어리가 이어붙어 한 편의 글이 되어 모델에 들어갑니다. 모델은 그 뒤를 이어 쓸 뿐입니다. `HELLO` 한 낱말만 이어 쓰게 만드는 것이 과제입니다.

## 입력 조건

- 영어 소문자로 된 낱말 하나가 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 낱말의 길이는 5자 이상 6자 이하입니다.

## 출력 조건

- 첫째 줄에 같은 단어를 대문자로 바꾸어 출력합니다.
- 출력의 길이는 5자 이상 6자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 영어 소문자 단어 하나입니다.
- 출력은 같은 단어를 대문자로 바꾼 것입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
hello
```

기대 출력

```
HELLO
```

**예시 2**

입력

```
judge
```

기대 출력

```
JUDGE
```

**예시 3**

입력

```
token
```

기대 출력

```
TOKEN
```

**예시 4**

입력

```
model
```

기대 출력

```
MODEL
```

**예시 5**

입력

```
local
```

기대 출력

```
LOCAL
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

따옴표, 마침표, 앞뒤 설명이 붙으면 오답입니다. 단어는 0.6B 가 철자를 흔들지 않는 짧은 것만 골랐습니다.
