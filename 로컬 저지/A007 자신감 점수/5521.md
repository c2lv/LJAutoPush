### 파이썬 코드

```python
def solution(N, warriors):
    confident = [False] * N

    for i in range(N):
        if warriors[i-1] < warriors[i] and warriors[(i+1)%N] < warriors[i]:
            confident[i] = True

    total = sum(confident)
    answer = 0

    for i in range(N):
        score = total - confident[i] - confident[i-1] - confident[(i+1)%N]

        if warriors[i-2] < warriors[i-1] and warriors[(i+1)%N] < warriors[i-1]:
            score += 1

        if warriors[i-1] < warriors[(i+1)%N] and warriors[(i+2)%N] < warriors[(i+1)%N]:
            score += 1

        answer = max(answer, score)

    return answer
```
