# [P18] 다섯 갈래 분류 (chat)

[문제 보기](https://localjudge.com/problems/P18)

> 선택지가 둘일 때와 다섯일 때는 난이도가 다릅니다. 문의를 환불·배송·기술·결제·계정 가운데 하나로 갈라보세요.

## 분류

300점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 분류, 라벨 쏠림, 한 줄 입력, 한국어

## 문제

고객 문의 한 문장이 들어옵니다. `환불` `배송` `기술` `결제` `계정` 다섯 중 하나만 출력해야 합니다.

| 들어오는 문장 | 내야 하는 답 |
| --- | --- |
| 지난달 결제 금액 돌려받고 싶습니다. | 환불 |

갈래 이름 말고는 아무것도 붙일 수 없습니다. `환불 문의로 보입니다` 처럼 문장으로 답하면 떨어집니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 16자 이상 24자 이하입니다.

## 출력 조건

- 첫째 줄에 `결제`, `계정`, `기술`, `배송`, `환불` 가운데 하나를 출력합니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 고객 문의 한 문장입니다.
- 출력은 다섯 갈래 가운데 하나입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
지난달 결제 금액 돌려받고 싶습니다.
```

기대 출력

```
환불
```

**예시 2**

입력

```
주문 취소하고 결제 취소해 주세요.
```

기대 출력

```
환불
```

**예시 3**

입력

```
두 번 결제됐는데 하나 되돌려 주세요.
```

기대 출력

```
환불
```

**예시 4**

입력

```
제 택배가 지금 어디쯤인가요?
```

기대 출력

```
배송
```

**예시 5**

입력

```
송장 번호가 나흘째 갱신이 안 됩니다.
```

기대 출력

```
배송
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

환불과 결제는 경계가 겹치도록 일부러 섞어 두었습니다.
