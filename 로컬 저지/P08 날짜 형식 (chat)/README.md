# [P08] 날짜 형식 (chat)

[문제 보기](https://localjudge.com/problems/P08)

> 같은 변환인데 조수 모드라서 설명이 따라붙습니다. 날짜 한 줄만 남게 만들어보세요.

## 분류

300점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 출력 형식, 변환, 설명 억제, 한 줄 입력, 한국어

## 문제

`YYYY년 M월 D일` 형태의 날짜가 한 줄로 들어옵니다. 같은 날짜를 `YYYY-MM-DD` 형태로 바꿔 출력해야 합니다.

| 들어오는 날짜 | 내야 하는 답 |
| --- | --- |
| 2026년 3월 7일 | 2026-03-07 |

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 11자 이상 13자 이하입니다.

## 출력 조건

- 첫째 줄에 `YYYY-MM-DD`를 출력합니다.
- 출력의 길이는 항상 10자입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `YYYY년 M월 D일`입니다.
- 출력은 `YYYY-MM-DD` 형태입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
2026년 3월 7일
```

기대 출력

```
2026-03-07
```

**예시 2**

입력

```
2025년 12월 25일
```

기대 출력

```
2025-12-25
```

**예시 3**

입력

```
2024년 1월 1일
```

기대 출력

```
2024-01-01
```

**예시 4**

입력

```
2026년 10월 8일
```

기대 출력

```
2026-10-08
```

**예시 5**

입력

```
2023년 9월 30일
```

기대 출력

```
2023-09-30
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

바꾸는 일 자체는 쉽습니다. 걸리는 자리가 두 군데입니다. 하나는 한 자리 수 월과 일에 `0` 을 붙여 두 자리로 맞추는 것입니다. `2026-3-7` 로 내면 떨어집니다. 다른 하나는 chat 모드라서 모델이 조수처럼 말을 거드는 것입니다. `2026-03-07 입니다` 처럼 한 마디가 붙으면 글자가 달라져 떨어집니다.

날짜 형식 (raw) 문제와 과제는 같고, 모드만 chat 입니다.
