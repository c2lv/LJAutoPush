# [V03] 별이 있는지 가리기

[문제 보기](https://localjudge.com/problems/V03)

> 그림에 별이 있으면 Y, 없으면 N 한 글자만 출력하게 만드세요. 모델은 Yes. 라고 답합니다.

## 분류

300점, chat, smolvlm-500m, 케이스 16, 최대 8토큰, 출제 dongbinna, 보통, 그림 읽기, 출력 형식, 그림 입력, 한국어

## 문제

그림에 노란 별이 있으면 `Y`, 없으면 `N` 을 출력하라. 한 글자만 출력한다.

별이 없는 그림에도 동그라미와 네모는 있다. 빈 그림이 아니다.

**모델은 이 과제를 완벽하게 한다.** 재 보니 16번 중 16번을 가려냈다. 그런데 글자 그대로 맞은 것은 0이었다. 모델이 `Yes.` `No.` 라고 답하기 때문이다. 보는 일은 끝났고, 남은 숙제는 그 말을 한 글자로 바꾸는 것뿐이다.

이 문제가 이 사이트가 하려는 말에 제일 가깝다. 모델이 못 해서 못 푸는 것이 아니라, **시킨 대로 말하게 만들지 못해서** 못 푸는 것이다.

이 문제의 입력은 글이 아니라 **그림**이다. 케이스마다 그림 한 장이 모델에 들어가고, 여러분이 쓴 글은 그 그림과 **같은 차례**에 들어간다. 그림을 말로 설명할 필요는 없다. 모델이 이미 보고 있다.

## 입력 조건

- 도형이 몇 개 그려진 그림. 그중에 노란 별이 있기도 하다

## 출력 조건

- `Y` 또는 `N` 한 글자
- 출력은 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 최대 8 토큰
- 케이스는 16개
- 답은 Y 또는 N 한 글자입니다. Yes 나 No 는 틀립니다
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 8 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

```
N
```

**예시 2**

```
Y
```

```
N
```

**예시 3**

입력

```
N
```
