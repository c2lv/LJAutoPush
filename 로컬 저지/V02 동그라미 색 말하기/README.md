# [V02] 동그라미 색 말하기

[문제 보기](https://localjudge.com/problems/V02)

> 동그라미 하나의 색을 영어 한 낱말로 출력하게 만드세요. 묻는 방식에 따라 결과가 크게 갈립니다.

## 분류

200점, chat, smolvlm-500m, 케이스 16, 최대 12토큰, 출제 dongbinna, 쉬움, 그림 읽기, 출력 형식, 그림 입력, 한국어

## 문제

그림에 색이 있는 동그라미가 하나 있습니다. 그 색을 영어 소문자 한 낱말로 출력해야 합니다.

답은 `red` `blue` `green` `yellow` `purple` 다섯 중 하나입니다.

| 들어오는 그림 | 내야 하는 답 |
| --- | --- |
| 빨간 동그라미 하나가 그려진 그림 | red |

이 문제에서 볼 것은 **같은 뜻인데 묻는 방식이 다르면 결과도 다르다**는 것입니다. 재 보니 그냥 물었을 때와 한 낱말로 답하라고 시켰을 때, 맞힌 개수는 둘 다 16이었는데 글자 그대로 맞은 것은 16과 1로 갈렸습니다. 형식을 시키는 말이 오히려 형식을 망가뜨린 셈입니다.

이 문제의 입력은 글이 아니라 **그림**입니다. 케이스마다 그림 한 장이 모델에 들어가고, 여러분이 쓴 글은 그 그림과 **같은 차례**에 들어갑니다. 그림을 말로 설명할 필요는 없습니다. 모델이 이미 보고 있습니다.

## 입력 조건

- 색이 있는 동그라미 하나가 그려진 그림
- 입력은 한 줄로 들어옵니다.

## 출력 조건

- red / blue / green / yellow / purple 중 하나. 소문자로
- 출력은 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 최대 12 토큰
- 케이스는 16개
- 답은 영어 소문자입니다. 대문자나 마침표가 붙으면 틀립니다
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 12 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
red
```

기대 출력

```
green
```

**예시 2**

입력

```
purple
```

기대 출력

```
blue
```

**예시 3**

입력

```
yellow
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

모델은 색을 아주 잘 봅니다(16/16). 이 문제는 보는 능력이 아니라 출력 형식을 다루는 문제입니다.
