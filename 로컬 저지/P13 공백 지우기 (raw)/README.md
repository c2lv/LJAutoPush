# [P13] 공백 지우기 (raw)

[문제 보기](https://localjudge.com/problems/P13)

> 가장 쉬운 형식 문제입니다. 받은 글에서 띄어쓰기를 전부 없애보세요.

## 분류

100점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 아주 쉬움, 출력 형식, 변환, 한 줄 입력, 한국어

## 문제

공백이 섞인 영어 소문자 문자열이 들어옵니다. 공백을 전부 지워 한 덩어리로 출력해야 합니다.

| 들어오는 문자열 | 내야 하는 답 |
| --- | --- |
| c o a x | coax |

## 입력 조건

- 영어 소문자와 공백으로 이루어진 문자열이 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 7자 이상 11자 이하입니다.
- 공백을 뺀 글자 수는 4자 이상 6자 이하입니다.

## 출력 조건

- 첫째 줄에 공백을 지운 문자열을 출력합니다.
- 출력의 길이는 4자 이상 6자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 공백이 섞인 소문자 문자열입니다.
- 출력은 공백을 지운 문자열입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

```
c o a x
```

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.
