## 프롬프트

### 낸 코드

```
SELECT e.name AS employee, c.name AS company, c.address AS company_city, e.address AS employee_city
FROM employee e
JOIN affiliation a ON e.employee_id = a.employee_id
JOIN company c ON a.company_id = c.company_id
WHERE e.address <> c.address
ORDER BY e.name ASC
```
