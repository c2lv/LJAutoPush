## 프롬프트

### 낸 코드

```
SELECT e.name, e.address
FROM employee AS e
JOIN affiliation AS a ON e.employee_id = a.employee_id
JOIN company AS c ON a.company_id = c.company_id
WHERE c.name = '천국테크'
ORDER BY e.name ASC
```
