### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
a = [0, 0] + [int(v) for v in data[1:1 + n]]
dp = [0] * (n + 2)
for i in range(2, n + 2):
    dp[i] = max(dp[i - 1], dp[i - 2] + a[i], (dp[i - 3] if i >= 3 else 0) + a[i - 1] + a[i])
print(dp[n + 1])
```
