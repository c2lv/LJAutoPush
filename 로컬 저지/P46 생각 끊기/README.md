# [P46] 생각 끊기

[문제 보기](https://localjudge.com/problems/P46)

> 생각을 아예 못 하게 만드는 방법이 있습니다. 생각이 길어져서 틀리는 문제라면 그쪽이 빠릅니다.

## 분류

300점, think, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 생각 주입, 설명 억제, 추출, 한 줄 입력, 한국어

## 문제

수가 하나 든 한국어 문장이 들어옵니다. 그 수를 아라비아 숫자로만 출력해야 합니다.

| 들어오는 문장 | 내야 하는 답 |
| --- | --- |
| 이 제품의 가격은 15000원입니다. | 15000 |

꺼내는 일 자체는 어렵지 않습니다. 이 문제가 재는 것은 think 칸을 어떻게 쓰느냐입니다. 생각이 길어지면 모델이 `15000원` 이나 `답은 15000입니다` 쪽으로 새기 쉽습니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 12자 이상 23자 이하입니다.

## 출력 조건

- 첫째 줄에 그 수를 숫자로만 출력합니다.
- 출력값은 2 이상 24874 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 수가 하나 포함된 한국어 문장입니다.
- 출력은 그 수를 숫자로만 적은 것입니다.
- **think 모드**입니다. assistant 턴의 생각 블록을 사람이 대신 채웁니다. 채점은 `</think>` 뒤부터만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
이 제품의 가격은 15000원입니다.
```

기대 출력

```
15000
```

**예시 2**

입력

```
참가자는 총 42명이었다.
```

기대 출력

```
42
```

**예시 3**

입력

```
배송은 3일 걸립니다.
```

기대 출력

```
3
```

**예시 4**

입력

```
강의실에 의자가 128개 있다.
```

기대 출력

```
128
```

**예시 5**

입력

```
대기 인원이 9명 남았습니다.
```

기대 출력

```
9
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

think 칸 안에서 당신이 직접 `</think>` 를 닫을 수 있습니다. 그러면 모델은 생각할 기회 없이 답부터 씁니다. 반칙이 아닙니다. 이 트랙에서 배워야 할 수법입니다.

생각을 길게 하게 만드는 쪽과 아예 끊어 버리는 쪽, 어느 쪽이 이 과제에 유리한지 직접 재어 보세요. 전체 프롬프트 카드에서 `</think>` 가 어디에 놓이는지 눈으로 확인하면서 하면 빠릅니다.
