### 파이썬 코드

```python
import sys

n = int(sys.stdin.read().split()[0])
dp = [0] * (n + 1)
for i in range(2, n + 1):
    b = dp[i - 1]
    if i % 2 == 0 and dp[i // 2] < b:
        b = dp[i // 2]
    if i % 3 == 0 and dp[i // 3] < b:
        b = dp[i // 3]
    dp[i] = b + 1
print(dp[n])
```
