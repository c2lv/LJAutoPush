### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n, m = int(data[0]), int(data[1])
vals = list(map(int, data[2:2 + n + m]))
vals.sort()
sys.stdout.write(" ".join(map(str, vals)) + "\n")
```
