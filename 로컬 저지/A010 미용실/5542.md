```python
def solution(N, reserved):
    reserved = sorted(reserved, key=lambda x: x[1])
    answer = 0
    last_end = 0
    for r in reserved:
        if r[0] >= last_end:
            last_end = r[1]
            answer += 1
    return answer
```
