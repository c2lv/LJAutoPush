## 프롬프트

### 낸 코드

```
SELECT 
    c.name AS name, 
    COUNT(e.employee_id) AS cnt, 
    AVG(a.pay) AS avg_pay
FROM 
    company c
JOIN 
    affiliation a ON c.company_id = a.company_id
JOIN 
    employee e ON a.employee_id = e.employee_id
GROUP BY 
    c.name
ORDER BY 
    c.name ASC
```
