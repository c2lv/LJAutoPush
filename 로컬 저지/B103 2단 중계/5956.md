### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
g = data[1:1 + n]
adj = [set(j for j in range(n) if g[i][j] == "Y") for i in range(n)]
best = 0
for i in range(n):
    s = set(adj[i])
    for j in adj[i]:
        s |= adj[j]
    s.discard(i)
    if len(s) > best:
        best = len(s)
print(best)
```
