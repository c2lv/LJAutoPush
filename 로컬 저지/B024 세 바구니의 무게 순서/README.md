# [B024] 세 바구니의 무게 순서

[문제 보기](https://localjudge.com/problems/B024)

> 세 바구니의 무게를 가벼운 것부터 한 줄에 늘어놓는다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 정렬, 기초 문법, 한국어

## 문제

한 과일 가게에서는 손님에게 보낼 과일을 바구니 세 개에 나누어 담는다. 담은 뒤에는 저울로 세 바구니의 무게를 차례대로 재고, 가벼운 바구니부터 차례대로 장부에 적는다. 장부에는 무게만 한 줄에 적으며, 바구니의 번호는 적지 않는다.

세 바구니의 무게가 주어질 때, 가벼운 것부터 차례대로 출력하는 프로그램을 작성하여라.

예를 들어 세 바구니의 무게가 다음의 표와 같다고 해보자. 저울에 올린 순서대로 1번, 2번, 3번 바구니의 무게를 적은 것이다.

| 바구니 | 1번 | 2번 | 3번 |
| --- | --- | --- | --- |
| 무게 | 83 | 515 | 45 |

이 가운데 가장 가벼운 바구니는 무게가 45인 3번 바구니다. 그다음은 무게가 83인 1번 바구니이고, 가장 무거운 바구니는 무게가 515인 2번 바구니다. 그래서 장부에 적히는 순서는 다음과 같다.

| 순서 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 바구니 | 3번 | 1번 | 2번 |
| 무게 | 45 | 83 | 515 |

따라서 이 경우 45, 83, 515를 이 순서대로 한 줄에 출력한다.

무게를 재는 순서와 장부에 적는 순서는 이처럼 다를 수 있다. 세 바구니의 무게가 무거운 것부터 주어지는 경우도 있다. 예를 들어 무게가 다음의 표와 같다고 해보자.

| 바구니 | 1번 | 2번 | 3번 |
| --- | --- | --- | --- |
| 무게 | 1000 | 999 | 998 |

이 경우 장부에 적히는 순서는 998, 999, 1000이 된다. 재어 둔 순서를 그대로 뒤집은 모양이다.

| 순서 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 바구니 | 3번 | 2번 | 1번 |
| 무게 | 998 | 999 | 1000 |

반면에 세 바구니의 무게가 이미 가벼운 것부터 주어졌다면, 주어진 순서를 그대로 적으면 된다.

## 입출력 예시

## 예시 1

입력

```
83 515 45
```

출력

```
45 83 515 
```

## 예시 2

입력

```
3 1 2
```

출력

```
1 2 3 
```

## 예시 3

입력

```
1000 999 998
```

출력

```
998 999 1000 
```

## 입력 조건

- 가장 먼저 첫째 줄에 세 바구니의 무게가 공백 하나로 구분되어 차례대로 주어진다. 각 무게는 1 이상 1,000 이하의 자연수다. 또한 세 바구니의 무게는 서로 다르다. 무게가 주어지는 순서는 바구니의 번호 순서이며, 무게의 크기 순서와는 관계가 없다.

## 출력 조건

- 세 바구니의 무게를 가벼운 것부터 차례대로 한 줄에 출력한다. 이때 각 무게 뒤에 공백을 하나 붙여서 출력한다. 그래서 줄의 마지막 무게 뒤에도 공백이 하나 남는다. 그 뒤에 줄을 한 번 바꾸고 끝낸다. 채점은 출력을 기대값과 글자 하나까지 견주므로, 줄 끝의 공백이 없으면 순서를 맞게 구했어도 틀린 답으로 처리된다.

## 요구사항

- 입력은 표준 입력으로 받고, 결과는 표준 출력으로 내보냅니다
- 가벼운 무게부터 차례대로 출력합니다
- 각 무게 뒤에 공백을 하나 붙입니다. 그래서 줄의 마지막 무게 뒤에도 공백이 하나 남습니다
- 결과는 한 줄로 출력합니다
- 채점은 출력을 기대값과 글자 하나까지 견줍니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
