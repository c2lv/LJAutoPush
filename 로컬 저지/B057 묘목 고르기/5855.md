### 파이썬 코드

```python
import sys
from itertools import combinations

n, m = map(int, sys.stdin.read().split()[:2])
out = ["".join("%d " % x for x in p) for p in combinations(range(1, n + 1), m)]
sys.stdout.write("\n".join(out) + "\n\n")
```
