### 파이썬 코드

```python
import sys
from bisect import bisect_left

data = sys.stdin.read().split()
n = int(data[0])
a = [-int(v) for v in data[1:1 + n]]
tails = []
for x in a:
    i = bisect_left(tails, x)
    if i == len(tails):
        tails.append(x)
    else:
        tails[i] = x
print(n - len(tails))
```
