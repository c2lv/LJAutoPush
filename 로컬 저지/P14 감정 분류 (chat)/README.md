# [P14] 감정 분류 (chat)

[문제 보기](https://localjudge.com/problems/P14)

> 리뷰 24개를 프롬프트 하나로 전부 맞혀야 합니다. 몇 개만 맞히는 프롬프트로는 통과하지 못합니다.

## 분류

200점, chat, qwen3-0.6b, 케이스 24, 최대 16토큰, 출제 dongbinna, 쉬움, 분류, 라벨 쏠림, 퓨샷 설계, 한 줄 입력, 한국어

## 문제

상품 리뷰 한 문장이 들어옵니다. `긍정` 또는 `부정` 둘 중 하나만 출력해야 합니다.

| 들어오는 리뷰 | 내야 하는 답 |
| --- | --- |
| 배터리가 생각보다 오래가서 만족합니다. | 긍정 |

조수는 `긍정적인 리뷰입니다` 처럼 문장으로 늘려 쓰거나 `Positive` 라고 영어로 답하기 쉽습니다. 두 낱말 가운데 하나만 나오게 막아야 합니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 14자 이상 23자 이하입니다.

## 출력 조건

- 첫째 줄에 `긍정`, `부정` 가운데 하나를 출력합니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 상품 리뷰 한 문장입니다.
- 출력은 `긍정` 또는 `부정` 가운데 하나입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 24개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 24개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 24개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
배터리가 생각보다 오래가서 만족합니다.
```

기대 출력

```
긍정
```

**예시 2**

입력

```
이틀 만에 고장났고 문의해도 답이 없네요.
```

기대 출력

```
부정
```

**예시 3**

입력

```
포장도 깔끔하고 배송도 빨랐어요.
```

기대 출력

```
긍정
```

**예시 4**

입력

```
사진이랑 색이 완전히 다릅니다.
```

기대 출력

```
부정
```

**예시 5**

입력

```
가격 생각하면 이 정도면 훌륭하죠.
```

기대 출력

```
긍정
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

케이스 전부를 하나의 프롬프트로 통과해야 합니다. 특정 문장에만 맞춘 풀이는 다른 케이스에서 깨집니다. 실무에서 쓰는 프롬프트도 이렇게 여러 입력을 한 번에 견뎌야 합니다.
