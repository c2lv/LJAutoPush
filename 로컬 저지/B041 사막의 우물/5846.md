### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
dist = data[1:n]
price = data[n:2 * n]
best = int(price[0])
total = 0
for i in range(n - 1):
    p = int(price[i])
    if p < best:
        best = p
    total += best * int(dist[i])
print(total)
```
