## 프롬프트

### 낸 코드

```
SELECT strftime('%m', datetime) AS month, COUNT(*) AS cnt
FROM registered_member
WHERE datetime BETWEEN '2012-07-01 00:00:00' AND '2012-09-30 23:59:59'
GROUP BY strftime('%m', datetime)
ORDER BY month
```
