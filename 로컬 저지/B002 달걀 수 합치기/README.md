# [B002] 달걀 수 합치기

[문제 보기](https://localjudge.com/problems/B002)

> 일꾼 두 사람이 바구니에 거둔 달걀을 한 상자에 옮겨 담았을 때의 달걀 수를 구한다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 기초 문법, 입출력, 한국어

## 문제

한 양계장에서는 아침마다 달걀을 거둔다. 일꾼 두 사람이 각자 바구니를 하나씩 들고 닭장을 돌며, 찾은 달걀을 자기 바구니에 담는다. 첫째 일꾼이 담은 달걀의 수를 A개, 둘째 일꾼이 담은 달걀의 수를 B개라고 하자.

두 사람이 닭장을 다 돌면 바구니를 창고로 가져온다. 창고에서는 두 바구니의 달걀을 모두 꺼내 하나의 상자에 옮겨 담는다. 옮기는 동안 깨지거나 빠지는 달걀은 없다. 또한 상자는 충분히 커서 두 바구니의 달걀이 모두 들어간다. 따라서 상자에 담기는 달걀의 수는 두 바구니에 담겨 있던 달걀의 수를 더한 값이 된다.

두 바구니에 담긴 달걀의 수가 주어졌을 때, 상자에 담기는 달걀의 수를 출력하는 프로그램을 작성하여라.

예를 들어 두 일꾼이 거둔 달걀의 수가 다음의 표와 같다고 해보자.

| 바구니 | 첫째 일꾼 | 둘째 일꾼 |
| --- | --- | --- |
| 달걀 수 | 1 | 2 |

첫째 일꾼의 바구니에 1개가 담겨 있고, 둘째 일꾼의 바구니에 2개가 담겨 있다. 창고 담당자는 빈 상자를 놓고 두 바구니를 차례대로 쏟는다. 상자에 담긴 달걀의 수가 늘어나는 중간 과정은 다음의 표와 같다.

| 단계 | 상자에 담긴 달걀 수 |
| --- | --- |
| 빈 상자를 놓은 뒤 | 0 |
| 첫째 바구니를 쏟은 뒤 | 1 |
| 둘째 바구니를 쏟은 뒤 | 3 |

두 바구니를 모두 쏟고 나면 상자에는 1과 2를 더한 3개의 달걀이 담긴다. 따라서 이 경우의 정답은 3이다.

다른 날의 결과까지 함께 표로 정리하면 다음과 같다.

| 첫째 일꾼 | 둘째 일꾼 | 상자에 담기는 달걀 수 |
| --- | --- | --- |
| 1 | 2 | 3 |
| 9 | 9 | 18 |
| 4 | 2 | 6 |

두 바구니 가운데 어느 쪽이 더 많은지는 따지지 않는다. 두 일꾼이 같은 수를 거둔 날도 있을 수 있다.

## 입출력 예시

## 예시 1

입력

```
1 2
```

출력

```
3
```

## 예시 2

입력

```
9 9
```

출력

```
18
```

## 예시 3

입력

```
4 2
```

출력

```
6
```

## 입력 조건

- 가장 먼저 첫째 줄에 두 일꾼이 거둔 달걀의 수 A와 B가 공백 하나로 구분되어 차례대로 주어진다. A는 첫째 일꾼의 바구니에 담긴 달걀의 수이고, B는 둘째 일꾼의 바구니에 담긴 달걀의 수다. A와 B는 각각 1 이상 9 이하의 자연수다. 두 수가 서로 같을 수도 있으며, 어느 쪽이 더 큰지에 대한 조건은 없다. 입력으로 주어지는 줄은 이 한 줄뿐이고, 두 수 사이의 공백은 하나다. 거둔 날짜나 일꾼의 이름 같은 값은 주어지지 않는다.

## 출력 조건

- 상자에 담기는 달걀의 수를 첫째 줄에 자연수 형태로 출력한다. 수 하나만 찍고 줄을 바꾸며, 수 뒤에 공백을 붙이지 않는다. 단위는 적지 않고 수만 찍는다.

## 요구사항

- 입력은 한 줄이고, 두 수가 공백 하나로 구분되어 주어집니다
- A와 B는 각각 1 이상 9 이하의 자연수입니다
- 두 수가 같을 수도 있습니다
- 답은 수 하나이며 한 줄에 출력합니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
