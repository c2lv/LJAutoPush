# [B008] 심야 버스 도착 시각

[문제 보기](https://localjudge.com/problems/B008)

> 출발 시각과 걸리는 시간이 주어졌을 때 심야 고속버스의 도착 시각을 구한다.

## 분류

200점, 케이스 15, 출제 dongbinna, 쉬움, 기초 문법, 조건문, 한국어

## 문제

한 회사의 심야 고속버스는 밤에도 쉬지 않고 달린다. 이 버스는 A시 B분에 터미널을 떠나며, 목적지에 닿기까지 C분이 걸린다. 길이 막히거나 중간에 쉬어 가는 일은 없다고 보고, 걸리는 시간은 늘 C분으로 본다.

터미널의 시계는 하루를 0시 0분부터 23시 59분까지로 적으며, 날짜는 적지 않는다. 그래서 걸리는 시간이 길어 도착 시각이 자정을 넘기면, 도착 시각은 다음 날의 시각이 된다. 이 경우에도 날짜는 적지 않고 시와 분만 적는다. 걸리는 시간이 최대 1,000분이므로 자정을 두 번 넘기는 일은 없다.

출발 시각과 걸리는 시간이 주어졌을 때, 버스의 도착 시각을 출력하는 프로그램을 작성하여라.

예를 들어 버스가 23시 59분에 떠나고 1,000분이 걸린다고 해보자. 시와 분을 따로 다루기보다, 출발 시각을 분으로 바꾸어 놓고 셈을 하는 편이 쉽다. 하루는 1,440분이므로, 더한 값이 1,440분을 넘으면 1,440분을 덜어 내면 된다. 중간 과정을 표로 적으면 다음과 같다.

| 단계 | 값 |
| --- | --- |
| 출발 시각을 분으로 바꾼 값 | 1439 |
| 걸리는 시간을 더한 값 | 2439 |
| 하루 1,440분을 덜어 낸 값 | 999 |
| 시와 분으로 되돌린 값 | 16시 39분 |

따라서 이 경우의 도착 시각은 16시 39분이다.

다른 경우까지 함께 표로 정리하면 다음과 같다.

| 출발 시각 | 10시 10분 | 23시 59분 | 23시 59분 | 0시 0분 |
| --- | --- | --- | --- | --- |
| 걸리는 시간 | 50분 | 1분 | 1,000분 | 0분 |
| 도착 시각 | 11시 0분 | 0시 0분 | 16시 39분 | 0시 0분 |

걸리는 시간이 0분인 경우도 있다. 이때 도착 시각은 출발 시각과 같다.

## 입출력 예시

## 예시 1

입력

```
10 10
50
```

출력

```
11 0
```

## 예시 2

입력

```
23 59
1000
```

출력

```
16 39
```

## 예시 3

입력

```
23 59
1
```

출력

```
0 0
```

## 입력 조건

- 가장 먼저 첫째 줄에 출발 시각의 시 A와 분 B가 공백 하나로 구분되어 차례대로 주어진다. A는 0 이상 23 이하의 정수이고, B는 0 이상 59 이하의 정수다. 이어서 둘째 줄에 목적지까지 걸리는 시간 C가 분 단위의 정수로 주어진다. C는 0 이상 1,000 이하의 정수이며, 0이 주어질 수도 있다. C가 시간 단위로 주어지는 경우는 없다. 출발 시각과 걸리는 시간은 서로 다른 줄에 주어지며, 한 줄에 함께 주어지지 않는다.

## 출력 조건

- 도착 시각의 시와 분을 첫째 줄에 공백 하나로 구분해 차례대로 출력한다. 시와 분은 앞에 0을 덧붙이지 않고 그 수만 그대로 적는다. 0시 10분이라면 0 10 으로 찍는다. 두 수 사이의 공백은 하나이며, 분 뒤에는 공백을 붙이지 않는다.

## 요구사항

- 입력은 두 줄이고, 첫째 줄에 시와 분, 둘째 줄에 걸리는 시간이 주어집니다
- A는 0 이상 23 이하, B는 0 이상 59 이하의 정수입니다
- C는 0 이상 1,000 이하의 정수이며 0일 수도 있습니다
- 도착 시각이 자정을 넘기면 다음 날의 시각으로 적습니다
- 시와 분 앞에 0을 덧붙이지 않습니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
