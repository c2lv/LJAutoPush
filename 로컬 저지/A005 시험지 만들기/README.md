# [A005] 시험지 만들기

[문제 보기](https://localjudge.com/problems/A005)

> 출제자는 N개의 문제를 출제하고자 한다.

## 분류

200점, 케이스 18, 출제 dongbinna, 쉬움, 정렬, 그리디, 한국어

## 문제

출제자는 N개의 문제를 출제하고자 한다. 각 N개의 문제에 대한 난이도에 대한 정보가 주어질 때, N개의 문제를 모두 사용하여 하나의 시험지를 구성하고자 한다.

이때, 시험에 참여하는 사람의 입장에서 문제를 풀어나갈 때 문제의 난이도가 급격하게 올라가거나 내려가지 않았으면 한다. 따라서 문제를 출제할 때, 인접한 두 개의 문제의 난이도 차이의 최댓값을 최소화하는 것이 목표다. 문제를 푸는 사람 중에서는 문제를 거꾸로 풀어나가거나, 중간부터 푸는 사람도 존재할 것이다. 따라서 1번과 N번도 인접한 문제로 간주한다.

N개의 문제에 대한 난이도 정보가 주어졌을 때, 인접한 두 개의 문제의 난이도 차이의 최대에 대한 최솟값을 계산하는 프로그램을 작성하여라. 예를 들어 N=5개의 문제의 각 난이도가 [1, 5, 3, 9, 2] 형태로 주어졌다고 가정하자. 이 경우 [1, 3, 9, 5, 2]로 각 문제를 배치하면, 인접한 두 개의 문제의 난이도 차이의 최댓값은 6이다.

## 입출력 예시

## 예시 1

입력

```
5, [1, 5, 3, 9, 2]
```

출력

```
6
```

## 예시 2

입력

```
7, [1, 5, 7, 2, 4, 6, 3]
```

출력

```
2
```

## 입력 조건

- 가장 먼저 문제의 개수 N이 주어진다. N은 100,000보다 작거나 같은 자연수 중 홀수로 주어진다.
- 이어서 각 문제에 대한 난이도에 대한 정보가 담긴 배열 arr가 주어진다. 이때 각 난이도의 값은 1 이상 100,000 이하의 자연수 중 하나이다.

## 출력 조건

- N개의 문제에 대한 난이도 정보가 주어졌을 때, 인접한 두 문제의 난이도 차이의 최대의 최솟값을 반환한다.

## 요구사항

- solution(N, arr) 함수를 만들고 답을 반환해야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 18개이고, 그 가운데 2개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 18개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.

공개 케이스 2개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 18개를 전부 통과해야 해결입니다.
