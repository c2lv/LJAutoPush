### 파이썬 코드

```python
import sys
from itertools import permutations

data = sys.stdin.read().split()
n = int(data[0])
a = [int(x) for x in data[1:1 + n]]
best = 0
for p in permutations(a):
    s = 0
    for i in range(n - 1):
        s += abs(p[i] - p[i + 1])
    if s > best:
        best = s
print(best)
```
