# [P45] 생각 심기

[문제 보기](https://localjudge.com/problems/P45)

> 모델이 생각하는 칸을 여러분이 대신 채웁니다. 모델은 시킨 지시보다 심어 둔 생각을 더 세게 듣습니다.

## 분류

200점, think, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 생각 주입, 출력 형식, 한 줄 입력, 한국어

## 문제

영어 소문자 낱말이 들어옵니다. 전부 대문자로 바꿔 출력해야 합니다.

| 들어오는 낱말 | 내야 하는 답 |
| --- | --- |
| hello | HELLO |

이 문제에는 칸이 **세 개**입니다. 세 번째 칸에 쓴 글은 assistant 턴의 `<think>` **안에** 심깁니다. 모델은 그것을 자기가 한 생각으로 여기고 이어서 생각합니다.

채점은 `</think>` 뒤부터 봅니다. 그래서 세 번째 칸에 적은 글은 채점에 들어가지 않고, 모델이 뒤이어 쓸 말을 정해 두는 데만 쓰입니다.

## 입력 조건

- 영어 소문자로 된 낱말 하나가 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 낱말의 길이는 5자 이상 6자 이하입니다.

## 출력 조건

- 첫째 줄에 같은 낱말을 대문자로 바꾸어를 출력합니다.
- 출력의 길이는 5자 이상 6자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 영어 소문자 낱말 하나입니다.
- 출력은 같은 낱말을 대문자로 바꾼 것입니다.
- **think 모드**입니다. assistant 턴의 생각 블록을 사람이 대신 채웁니다. 채점은 `</think>` 뒤부터만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
hello
```

기대 출력

```
HELLO
```

**예시 2**

입력

```
judge
```

기대 출력

```
JUDGE
```

**예시 3**

입력

```
token
```

기대 출력

```
TOKEN
```

**예시 4**

입력

```
model
```

기대 출력

```
MODEL
```

**예시 5**

입력

```
local
```

기대 출력

```
LOCAL
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

모델은 같은 내용이라도 지시로 받을 때와 자기 생각으로 받을 때를 다르게 듣습니다. 지시는 "그렇게 해라" 이고, 심어 둔 생각은 "나는 이미 그렇게 정했다" 이기 때문입니다. 두 칸으로만 풀어 보고, 그다음 세 번째 칸을 써 보세요.
