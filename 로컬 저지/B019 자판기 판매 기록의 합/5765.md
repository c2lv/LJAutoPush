### 파이썬 코드

```python
import sys

# 입력 받기
N = int(sys.stdin.readline().strip())
record = sys.stdin.readline().strip()

# 총 판매 개수 계산
total_sales = sum(int(record[i]) for i in range(N))

# 출력
print(total_sales)
```
