### 파이썬 코드

```python
def solution(N, K, M, arr):
    cnt = 0
    for mask in range(1, 1 << N):
        c = bin(mask).count("1")
        if c > K or c % 2 == 0:
            continue
        s = 0
        for i in range(N):
            if (mask >> i) & 1:
                s += arr[i]
        if s >= M:
            cnt += 1
    return cnt
```
