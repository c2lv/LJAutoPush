### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
vals = [int(x) for x in data[1:1 + n]]
m = max(vals)
total = 0.0
for s in vals:
    total += s / m * 100
avg = total / n
if avg == int(avg):
    print(int(avg))
else:
    print(repr(avg))
```
