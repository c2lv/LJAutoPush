## 프롬프트

### 낸 코드

```
SELECT e.name, a.company_id, a.pay
FROM employee e
JOIN affiliation a ON e.employee_id = a.employee_id
JOIN (
    SELECT company_id, AVG(pay) AS avg_pay
    FROM affiliation
    GROUP BY company_id
) c ON a.company_id = c.company_id
WHERE a.pay > c.avg_pay
ORDER BY e.name ASC
```
