# [B007] 사전 점검 시각

[문제 보기](https://localjudge.com/problems/B007)

> 생방송 시각보다 45분 앞선 송출 장비 점검 시각을 구한다.

## 분류

200점, 케이스 15, 출제 dongbinna, 쉬움, 기초 문법, 조건문, 한국어

## 문제

한 방송국은 하루 24시간 동안 쉬지 않고 방송을 내보낸다. 생방송이 하나 잡히면, 기술 담당자는 그 시각보다 45분 앞선 시각에 송출 장비를 점검한다. 점검에 걸리는 시간이 꼭 45분이라서, 점검을 마치면 바로 생방송이 시작되는 셈이다.

담당자가 쓰는 시계는 하루를 0시 0분부터 23시 59분까지로 적으며, 날짜는 적지 않는다. 그래서 생방송 시각에서 45분을 앞당기다가 0시 0분보다 앞서게 되면, 점검 시각은 전날의 시각이 된다. 이 경우에도 날짜는 적지 않고 시와 분만 적는다.

생방송 시각이 주어졌을 때, 사전 점검 시각을 출력하는 프로그램을 작성하여라.

예를 들어 생방송 시각이 10시 10분이라고 해보자. 10분에서 45분을 그대로 뺄 수는 없으므로, 한 시간을 분으로 바꾸어 끌어와야 한다. 즉 10시 10분은 9시 70분과 같고, 여기서 45분을 빼면 9시 25분이 된다. 중간 과정을 표로 적으면 다음과 같다.

| 단계 | 시 | 분 |
| --- | --- | --- |
| 생방송 시각 | 10 | 10 |
| 한 시간을 분으로 끌어온 뒤 | 9 | 70 |
| 45분을 뺀 뒤 | 9 | 25 |

따라서 이 경우의 점검 시각은 9시 25분이다.

반면에 생방송 시각이 0시 0분이라고 해보자. 끌어올 시간이 없으므로 23시로 넘어가며, 0시 0분에서 45분을 앞당긴 시각은 전날 23시 15분이 된다. 다른 경우까지 함께 표로 정리하면 다음과 같다.

| 생방송 시각 | 10시 10분 | 0시 0분 | 0시 45분 | 23시 59분 |
| --- | --- | --- | --- | --- |
| 점검 시각 | 9시 25분 | 23시 15분 | 0시 0분 | 23시 14분 |

분이 45분 이상이면 시는 그대로 두고 분에서 45를 빼면 된다. 0시 45분이 0시 0분이 되는 경우가 그렇다.

## 입출력 예시

## 예시 1

입력

```
10 10
```

출력

```
9 25
```

## 예시 2

입력

```
0 0
```

출력

```
23 15
```

## 예시 3

입력

```
0 45
```

출력

```
0 0
```

## 입력 조건

- 가장 먼저 첫째 줄에 생방송 시각의 시 H와 분 M이 공백 하나로 구분되어 차례대로 주어진다. H는 0 이상 23 이하의 정수이고, M은 0 이상 59 이하의 정수다. 즉 0 0 부터 23 59 까지가 들어올 수 있다. 시와 분은 앞에 0을 덧붙이지 않은 형태로 주어진다. 날짜나 요일 같은 값은 주어지지 않는다. 입력으로 주어지는 줄은 이 한 줄뿐이고, 두 수 사이의 공백은 하나다.

## 출력 조건

- 사전 점검 시각의 시와 분을 첫째 줄에 공백 하나로 구분해 차례대로 출력한다. 시와 분은 앞에 0을 덧붙이지 않고 그 수만 그대로 적는다. 0시 15분이라면 0 15 로 찍는다. 두 수 사이의 공백은 하나이며, 분 뒤에는 공백을 붙이지 않는다.

## 요구사항

- 입력은 한 줄이고, 두 수가 공백 하나로 구분되어 주어집니다
- H는 0 이상 23 이하, M은 0 이상 59 이하의 정수입니다
- 0시 0분보다 앞서게 되면 전날의 시각으로 넘어갑니다
- 시와 분을 공백 하나로 구분해 한 줄에 찍습니다
- 시와 분 앞에 0을 덧붙이지 않습니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
