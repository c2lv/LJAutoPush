### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
best = -1.0
cur = 0.0
for i in range(1, n + 1):
    v = float(data[i])
    cur = v if cur * v < v else cur * v
    if cur > best:
        best = cur
print("%.3f" % best)
```
