### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
a = [int(v) for v in data[1:1 + n]]
x = int(data[1 + n])
s = set(a)
cnt = 0
for v in a:
    w = x - v
    if w > v and w in s:
        cnt += 1
print(cnt)
```
