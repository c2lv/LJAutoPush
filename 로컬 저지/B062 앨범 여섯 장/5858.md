### 파이썬 코드

```python
import sys
from itertools import combinations

data = sys.stdin.read().split()
pos = 0
out = []
while pos < len(data):
    k = int(data[pos])
    if k == 0:
        break
    nums = data[pos + 1:pos + 1 + k]
    pos += 1 + k
    for c in combinations(nums, 6):
        out.append("".join(x + " " for x in c))
    out.append("")
sys.stdout.write("\n".join(out) + "\n")
```
