# [P12] 파이프로 잇기 (raw)

[문제 보기](https://localjudge.com/problems/P12)

> 쉼표로 들어온 낱말들을 대문자로 바꾸고 파이프로 다시 잇습니다. 두 가지 일을 한 번에 시켜보세요.

## 분류

200점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 출력 형식, 변환, 한 줄 입력, 한국어

## 문제

영어 소문자 단어 셋이 쉼표와 공백으로 구분되어 들어옵니다. 전부 대문자로 바꾸고 ` | ` (공백 파이프 공백) 으로 다시 이어 한 줄로 출력해야 합니다.

들어오는 입력은 이렇습니다.

```
coax, margin, cloud
```

내야 하는 답은 이렇습니다.

```
COAX | MARGIN | CLOUD
```

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 18자 이상 20자 이하입니다.

## 출력 조건

- 첫째 줄에 `A | B | C`를 출력합니다.
- 출력의 길이는 20자 이상 22자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `a, b, c` 형태입니다.
- 출력은 `A | B | C` 형태입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
coax, margin, cloud
```

기대 출력

```
COAX | MARGIN | CLOUD
```

**예시 2**

입력

```
judge, stone, green
```

기대 출력

```
JUDGE | STONE | GREEN
```

**예시 3**

입력

```
token, water, music
```

기대 출력

```
TOKEN | WATER | MUSIC
```

**예시 4**

입력

```
model, paper, apple
```

기대 출력

```
MODEL | PAPER | APPLE
```

**예시 5**

입력

```
local, cloud, table
```

기대 출력

```
LOCAL | CLOUD | TABLE
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

한 번에 두 가지 일을 시키는 문제입니다. 모델은 둘 가운데 하나만 하기 쉽습니다. 대문자로는 바꾸고 쉼표를 그대로 두거나, 파이프로 잇기는 하면서 소문자를 그대로 둡니다. 구분자도 틀리기 쉬운 자리입니다. 파이프 앞뒤의 공백 하나까지 기대값과 같아야 합니다.
