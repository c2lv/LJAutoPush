# [V05] 왼쪽인가 오른쪽인가

[문제 보기](https://localjudge.com/problems/V05)

> 동그라미가 화면 왼쪽에 있으면 Y, 오른쪽이면 N 을 출력하게 만드세요.

## 분류

300점, chat, smolvlm-500m, 케이스 16, 최대 8토큰, 출제 dongbinna, 보통, 그림 읽기, 자리 잡기, 그림 입력, 한국어

## 문제

그림에 보라색 동그라미가 하나 있습니다. 그것이 화면 **왼쪽 절반**에 있으면 `Y`, 오른쪽 절반에 있으면 `N` 을 출력해야 합니다.

| 동그라미의 자리 | 내야 하는 답 |
| --- | --- |
| 화면 왼쪽 절반 | Y |
| 화면 오른쪽 절반 | N |

가운데에 걸친 것은 없습니다. 확실히 한쪽에 있습니다.

이 문제의 입력은 글이 아니라 **그림**입니다. 케이스마다 그림 한 장이 모델에 들어가고, 여러분이 쓴 글은 그 그림과 **같은 차례**에 들어갑니다. 그림을 말로 설명할 필요는 없습니다. 모델이 이미 보고 있습니다.

재 보니 16번 중 13번이었습니다. 셋 중 고르기(왼쪽·가운데·오른쪽)로 물으면 모델이 거의 못 합니다. 둘 중 고르기로 줄이면 됩니다. 자리를 보는 일이 이 모델에게는 쉽지 않은 축에 듭니다.

## 입력 조건

- 보라색 동그라미 하나가 한쪽에 치우쳐 그려진 그림
- 입력은 한 줄로 들어옵니다.

## 출력 조건

- `Y`(왼쪽) 또는 `N`(오른쪽) 한 글자
- 출력은 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 최대 8 토큰
- 케이스는 16개
- 답은 Y 또는 N 한 글자입니다
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 8 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
Y
```

기대 출력

```
N
```

**예시 2**

입력

```
Y
```

기대 출력

```
N
```

**예시 3**

입력

```
N
```
