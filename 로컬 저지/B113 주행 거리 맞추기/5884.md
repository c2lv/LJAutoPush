### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n, m = int(data[0]), int(data[1])
a = [int(v) for v in data[2:2 + n]]
cnt = 0
s = 0
lo = 0
for hi in range(n):
    s += a[hi]
    while s > m:
        s -= a[lo]
        lo += 1
    if s == m:
        cnt += 1
print(cnt)
```
