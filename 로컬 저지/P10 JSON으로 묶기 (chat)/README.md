# [P10] JSON으로 묶기 (chat)

[문제 보기](https://localjudge.com/problems/P10)

> 조수 모드의 모델은 JSON 을 코드블록으로 감싸고 싶어 합니다. 그 습관을 눌러보세요.

## 분류

400점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 어려움, 출력 형식, 구조화 출력, 설명 억제, 한 줄 입력, 한국어

## 문제

JSON으로 묶기 (raw) 문제와 사실상 같은 문제입니다. chat 모드 문제입니다.

`이름: 홍길동, 나이: 25` 같은 한 줄이 들어옵니다. 공백을 뺀 JSON 한 줄로 바꿔 출력해야 합니다.

| 들어오는 문장 | 내야 하는 답 |
| --- | --- |
| 이름: 김철수, 나이: 30 | {"name":"김철수","age":30} |

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 항상 15자입니다.

## 출력 조건

- 첫째 줄에 압축 JSON 한 줄을 출력합니다.
- 출력의 길이는 항상 23자입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `이름: 홍길동, 나이: 25`입니다.
- 출력은 공백을 뺀 JSON 한 줄입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
이름: 김철수, 나이: 30
```

기대 출력

```
{"name":"김철수","age":30}
```

```

```

**예시 3**


기대 출력

```
{"name":"이준호","age":41}
```

**예시 4**

```
이름: 최민서, 나이: 19
```

기대 출력

```
{"name":"최민서","age":19}
```

**예시 5**

```

```

```

```
