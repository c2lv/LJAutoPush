# [P47] 생각으로 말투 누르기

[문제 보기](https://localjudge.com/problems/P47)

> 고칠 수 없는 system 지시와 여러분이 심어 둔 생각이 맞붙습니다. 어느 쪽이 이기는지 확인해보세요.

## 분류

400점, think, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 어려움, 생각 주입, 지시 계층, 계산, 한 줄 입력, 한국어

## 문제

고정된 **system 턴**이 모든 답을 존댓말 문장으로 풀어서 설명하라고 지시합니다. 당신은 그것을 지울 수 없습니다.

밑에 깔린 과제는 곱셈입니다. 출력에는 **정수만** 남아야 하고, `습니다` 와 `입니다` 는 금지어입니다.

| 들어오는 줄 | 내야 하는 답 |
| --- | --- |
| `3 * 4` | `12` |

곱셈 자체는 이 모델에게도 쉽습니다. 걸리는 자리는 말투입니다. 그냥 두면 `3 곱하기 4는 12입니다` 처럼 문장으로 답하고, 금지어가 들어간 그 한 마디 때문에 수를 맞혀도 그 케이스는 떨어집니다.

## 입력 조건

- `X * Y` 형태의 문자열이 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- X는 2 이상 22 이하의 자연수입니다.
- Y는 3 이상 19 이하의 자연수입니다.
- 수와 연산자 사이에는 공백이 하나씩 있습니다.

## 출력 조건

- 첫째 줄에 곱한 결과를 정수로 출력합니다.
- 출력값은 12 이상 132 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `X * Y` 형태의 문자열입니다.
- 출력은 곱한 결과 정수입니다. 다른 글자는 붙이지 마세요.
- **think 모드**입니다. assistant 턴의 생각 블록을 사람이 대신 채웁니다. 채점은 `</think>` 뒤부터만 봅니다.
- 출력의 **마지막 정수**만 봅니다. 앞에 과정을 적어도 됩니다.
- 출력에 `습니다`, `입니다` 가운데 하나라도 들어가면 그 케이스는 떨어집니다.
- 이 문제에는 **system 프롬프트가 미리 박혀 있습니다.** 내용은 아래 전체 프롬프트 보기에서 확인할 수 있고, 지울 수 없습니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
3 * 4
```

기대 출력

```
12
```

**예시 2**

입력

```
7 * 8
```

기대 출력

```
56
```

**예시 3**

입력

```
12 * 5
```

기대 출력

```
60
```

**예시 4**

입력

```
9 * 9
```

기대 출력

```
81
```

**예시 5**

입력

```
6 * 11
```

기대 출력

```
66
```
