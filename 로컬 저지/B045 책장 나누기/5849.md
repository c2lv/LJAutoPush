### 파이썬 코드

```python
import sys

n, k = map(int, sys.stdin.read().split()[:2])
base = k * (k + 1) // 2
if n < base:
    print(-1)
elif (n - base) % k == 0:
    print(k - 1)
else:
    print(k)
```
