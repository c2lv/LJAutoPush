# [A025] 왕복 달리기

[문제 보기](https://localjudge.com/problems/A025)

> 한 학생이 일직선상의 달리기 트랙 위에 서 있으며, 초기에는 0의 위치에 서 있다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 기초 문법, 시뮬레이션, 구현, 한국어

## 문제

한 학생이 일직선상의 달리기 트랙 위에 서 있으며, 초기에는 0의 위치에 서 있다. 이 학생은 왕복 달리기를 수행하려고 한다. 총 N개의 지점이 일직선상에 존재할 때, 학생은 1번 지점부터 N번 지점까지 차례대로 모두 터치하는 것이 목표다. 다만, 0에서부터 가까운 K개의 지점에 대해서는 해당 지점을 터치한 뒤에 즉시 다시 위치 0으로 돌아와야 하는 규칙이 존재한다. 구체적으로 K는 1 이상 N-1 이하의 자연수다.

학생은 1만큼의 거리를 이동하기 위하여 1초만큼의 시간이 소요되며, 결과적으로 N개의 모든 지점을 터치했을 때 달리기가 종료된다. 달리기가 종료될 때까지 걸리는 시간을 계산하는 프로그램을 작성하여라.

입력으로는 크기가 N인 1차원 배열이 주어지며, 각 지점까지의 위치가 0에서부터 가까운 순으로 오름차순 정렬되어 있는 형태로 입력이 주어진다. 예를 들어 N=6, K=3일 때, 다음과 같이 각 지점의 위치가 주어진 상황을 가정하자.

| 번호 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 위치 | 3 | 7 | 10 | 12 | 15 | 19 |

현재 예시에서 1번 지점, 2번 지점, 3번 지점에 대해서는 도달 이후에 위치 0으로 돌아와야 하기 때문에, 본 예시에서 필요한 총 소요 시간은 3 + 3 + 7 + 7 + 10 + 10 + 12 + 3 + 4 = 59초다.

## 입출력 예시

## 예시 1

입력

```
6, 3, [3, 7, 10, 12, 15, 19]
```

출력

```
59
```

## 예시 2

입력

```
10, 5, [1, 3, 3, 5, 6, 9, 10, 15, 20, 25]
```

출력

```
61
```

## 입력 조건

- 가장 먼저 지점의 수 N이 자연수로 주어진다. N은 3 이상 200,000 이하의 자연수다.
- 이어서 터치하고 돌아올 지점의 수 K가 자연수로 주어진다. K는 N-1 이하의 자연수다.
- 이어서 1번부터 N번까지의 지점의 위치에 대한 정보가 담긴 배열 arr가 주어진다. 각 위치 값은 1,000,000,000보다 작거나 같은 자연수다. 이때, 각 위치의 값은 서로 중복되지 않는다. 입력 배열 arr는 위치 값이 오름차순 정렬되어 있는 형태로 입력이 주어진다.

## 출력 조건

- 본 문제의 조건을 만족하며, 학생이 N개의 지점을 모두 터치하기 위해 필요한 시간을 반환한다.

## 요구사항

- solution(N, K, arr) 함수를 만들고 답을 반환해야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 2개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.

## 예시

공개 케이스 2개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 15개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
6, 3, [3, 7, 10, 12, 15, 19]
```

기대 출력

```
59
```

**예시 2**

입력

```
10, 5, [1, 3, 3, 5, 6, 9, 10, 15, 20, 25]
```

기대 출력

```
61
```
