# [B020] 도안 가로 확대

[문제 보기](https://localjudge.com/problems/B020)

> 도안의 각 기호를 R번씩 이어 붙여 가로로 늘린 도안을 출력한다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 기초 문법, 문자열, 한국어

## 문제

한 공방은 뜨개질 도안을 글자로 적어 둔다. 도안은 한 줄의 문자열이고, 문자열에 쓰인 기호 하나가 도안의 한 칸을 뜻한다. 기호가 다르면 그 칸에 뜨는 실의 색이 다르다.

이 공방은 같은 무늬를 더 넓게 뜨고 싶을 때 도안을 가로로 늘려서 쓴다. 도안을 가로로 R배 늘리려면 도안의 각 기호를 왼쪽부터 차례대로 R번씩 이어 붙이면 된다. 예를 들어 도안이 ABC이고 배율이 3이라면, A를 3번 적고 이어서 B를 3번 적고 이어서 C를 3번 적어서 AAABBBCCC가 된다. 늘린 도안의 길이는 원래 도안의 길이와 배율을 곱한 값이다. 배율이 1이면 도안은 그대로다.

공방은 도안을 여러 개 늘려야 하는데, 도안마다 배율이 다르다. 도안은 한 줄에 하나씩 적혀 있고, 한 줄에는 그 도안의 배율과 도안이 공백 하나로 나뉘어 들어 있다. 공백 앞이 배율이고 공백 뒤가 도안이다. 도안 자체에는 공백이 들어가지 않으므로 한 줄에 들어 있는 공백은 언제나 하나뿐이다.

총 T개의 도안과 각 도안의 배율이 주어졌을 때, 늘린 도안을 차례대로 출력하는 프로그램을 작성하여라.

예를 들어 T=2개의 도안이 주어졌고, 각 도안의 배율과 내용이 다음의 표와 같다고 해보자.

| 도안 번호 | 배율 | 도안 | 도안의 길이 |
| --- | --- | --- | --- |
| 1 | 3 | ABC | 3 |
| 2 | 5 | /HTP | 4 |

1번 도안은 기호가 A, B, C 셋이고 배율이 3이므로 기호마다 3번씩 이어 붙인다. 2번 도안은 기호가 /, H, T, P 넷이고 배율이 5이므로 기호마다 5번씩 이어 붙인다. 그 결과는 다음과 같다.

| 도안 번호 | 늘린 도안 | 늘린 도안의 길이 |
| --- | --- | --- |
| 1 | AAABBBCCC | 9 |
| 2 | /////HHHHHTTTTTPPPPP | 20 |

2번 도안처럼 영문 글자가 아닌 기호가 섞여 있어도 가리지 않고 똑같이 늘린다. 도안에 같은 기호가 여러 번 나오는 경우에도 나오는 자리마다 따로 R번씩 늘린다.

## 입출력 예시

## 예시 1

입력

```
2
3 ABC
5 /HTP
```

출력

```
AAABBBCCC
/////HHHHHTTTTTPPPPP
```

## 예시 2

입력

```
2
4 N3CJRWPB5
1 02X
```

출력

```
NNNN3333CCCCJJJJRRRRWWWWPPPPBBBB5555
02X
```

## 예시 3

입력

```
1
2 C8eAVXXQPKJ
```

출력

```
CC88eeAAVVXXXXQQPPKKJJ
```

## 입력 조건

- 가장 먼저 도안의 수 T가 첫째 줄에 주어진다. T는 1 이상 20 이하의 자연수다.
- 이어서 T개의 줄에 걸쳐 각 도안의 정보가 도안 번호 순서대로 주어진다. 각 줄에는 배율 R이 먼저 주어지고, 공백을 하나 둔 다음에 도안 문자열 S가 주어진다. R은 1 이상 8 이하의 자연수다. S는 영문 대문자와 소문자, 숫자, 기호로 이루어지며 공백을 포함하지 않는다. S의 길이는 1 이상 20 이하다.

## 출력 조건

- T개의 줄을 출력한다. i번째 줄에는 i번째 도안을 가로로 R배 늘린 결과를 적는다. 기호 사이에 공백은 넣지 않으며, 줄의 끝에도 공백을 남기지 않는다. 마지막 T번째 줄 다음에 빈 줄을 더 붙이지 않는다.

## 요구사항

- 입력은 표준 입력으로 받고 답은 표준 출력으로 내보냅니다
- 각 줄의 첫 수는 배율이고, 공백 뒤가 도안입니다
- 도안에는 영문 대소문자와 숫자뿐 아니라 기호도 섞일 수 있습니다. 글자 종류를 가리지 않고 그대로 늘려야 합니다
- 늘린 도안은 한 줄에 하나씩 출력합니다. 기호 사이에 공백을 넣으면 틀린 답이 됩니다
- 채점은 출력을 기대값과 **글자 하나까지** 견줍니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
