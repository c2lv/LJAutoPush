### 파이썬 코드

```python
import sys

# 입력 받기
input = sys.stdin.read
data = input().splitlines()

# 첫 줄은 도안의 수 T
T = int(data[0])

# 결과를 저장할 리스트
result = []

# 각 도안 처리
for i in range(1, T + 1):
    # 배율과 도안 분리
    R, S = data[i].split()
    R = int(R)
    
    # 도안을 R배 늘리기
    expanded_design = ''.join([char * R for char in S])
    
    # 결과에 추가
    result.append(expanded_design)

# 결과 출력
for line in result:
    print(line)
```
