# [V01] 그림 속 숫자 읽기

[문제 보기](https://localjudge.com/problems/V01)

> 그림에 두 자리 수가 크게 적혀 있습니다. 그 숫자만 출력하게 만드세요.

## 분류

100점, chat, smolvlm-500m, 케이스 16, 최대 16토큰, 출제 dongbinna, 아주 쉬움, 그림 읽기, 출력 형식, 그림 입력, 한국어

## 문제

그림 한가운데에 두 자리 수가 적혀 있습니다. 그 수만 출력해야 합니다.

이 갈래는 모델이 제일 잘하는 자리입니다. 재 보니 맨 질문으로도 16번 중 15번을 맞혔습니다. 어려운 쪽은 읽기가 아니라 형식입니다. 그림에 `42` 가 적혀 있을 때 출력이 어떻게 갈리는지 보면 이렇습니다.

| 모델이 낸 출력 | 채점 |
| --- | --- |
| `42` | 통과 |
| `42.` | 떨어짐 |
| `The number shown is 42.` | 떨어짐 |

문장 앞부분만 주는 방식이 잘 들었습니다. 질문을 던지면 모델이 답을 하려 들고, 앞부분을 주면 이어 쓰는 것 말고 할 일이 없습니다.

이 문제의 입력은 글이 아니라 **그림**입니다. 케이스마다 그림 한 장이 모델에 들어가고, 여러분이 쓴 글은 그 그림과 **같은 차례**에 들어갑니다. 그림을 말로 설명할 필요는 없습니다. 모델이 이미 보고 있습니다.

## 입력 조건

- 두 자리 수가 적힌 그림 한 장
- 입력은 한 줄로 들어옵니다.

## 출력 조건

- 그 수를 숫자로. 다른 글자 없이
- 출력은 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 최대 16 토큰
- 케이스는 16개
- 입력이 그림입니다. 글이 아닙니다
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
42
```

기대 출력

```
17
```

**예시 2**

입력

```
93
```

기대 출력

```
58
```

**예시 3**

입력

```
26
```
