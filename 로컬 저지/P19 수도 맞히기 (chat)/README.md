# [P19] 수도 맞히기 (chat)

[문제 보기](https://localjudge.com/problems/P19)

> 모델이 이미 아는 것을 묻는 문제입니다. 다만 문장이 아니라 낱말 하나만 나오게 만들어야 합니다.

## 분류

200점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 지식 보강, 설명 억제, 한 줄 입력, 한국어

## 문제

나라 이름이 들어옵니다. 그 나라의 수도를 **한 단어로만** 출력해야 합니다.

| 들어오는 줄 | 내야 하는 답 |
| --- | --- |
| `프랑스` | `파리` |

모델이 모르는 내용이 아닙니다. 수도 이름은 이미 알고 있습니다. 어려운 쪽은 그 이름 하나만 남기는 것입니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 2자 이상 5자 이하입니다.

## 출력 조건

- 첫째 줄에 수도 이름 한 단어를 출력합니다.
- 출력의 길이는 1자 이상 5자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 나라 이름입니다.
- 출력은 수도 이름 한 단어입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
프랑스
```

기대 출력

```
파리
```

**예시 2**

입력

```
일본
```

기대 출력

```
도쿄
```

**예시 3**

입력

```
영국
```

기대 출력

```
런던
```

**예시 4**

입력

```
이탈리아
```

기대 출력

```
로마
```

**예시 5**

입력

```
태국
```

기대 출력

```
방콕
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

조수는 `프랑스의 수도는 파리입니다` 라고 쓰려 듭니다. 그 여지를 없애는 것이 과제입니다.
