### 파이썬 코드

```python
def solution(N, house):
    answer = 0
    family = [[0, 0] for _ in range(4)]
    for y in range(N):
        for x in range(N):
            for i in range(4):
                if house[y][x] == i + 1:
                    family[i][0] = x
                    family[i][1] = y
    for i in range(4):
        answer += abs(family[i][0] - family[(i+1)%4][0]) + abs(family[i][1] - family[(i+1)%4][1])
    return answer
```
