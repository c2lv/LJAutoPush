# [P06] 숫자만 꺼내기 (chat)

[문제 보기](https://localjudge.com/problems/P06)

> 같은 추출을 조수 모드로 합니다. 모델이 "답은 15입니다" 처럼 문장으로 감싸려 하는 것을 막아야 합니다.

## 분류

300점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 출력 형식, 추출, 설명 억제, 한 줄 입력, 한국어

## 문제

숫자만 꺼내기 (raw) 문제와 사실상 같은 문제입니다. chat 모드 문제입니다.

한국어 문장 하나가 들어오고, 그 안에 수가 정확히 하나 있습니다. 그 수를 아라비아 숫자로만 출력해야 합니다.

| 들어오는 문장 | 내야 하는 답 |
| --- | --- |
| 이 제품의 가격은 15000원입니다. | 15000 |

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 12자 이상 23자 이하입니다.

## 출력 조건

- 첫째 줄에 그 수를 숫자로만을 정수로 출력합니다.
- 출력값은 2 이상 24874 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 수가 하나 포함된 한국어 문장입니다.
- 출력은 그 수를 숫자로만 적은 것입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
이 제품의 가격은 15000원입니다.
```

기대 출력

```
15000
```

**예시 2**

입력

```
참가자는 총 42명이었다.
```

기대 출력

```
42
```

**예시 3**

입력

```
배송은 3일 걸립니다.
```

기대 출력

```
3
```

**예시 4**

입력

```
강의실에 의자가 128개 있다.
```

기대 출력

```
128
```

**예시 5**

입력

```
대기 인원이 9명 남았습니다.
```

기대 출력

```
9
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

조수는 `15000원` 처럼 단위를 붙이거나 `답은 15000입니다` 라고 문장으로 감싸려 듭니다. 쉼표를 넣은 `15,000` 도 기대값과 달라 떨어집니다.
