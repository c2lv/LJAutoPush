### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
k = int(data[0])
n = int(data[1])
f = [int(x) for x in data[2:2 + k]]
lo, hi = 1, max(f)
while lo < hi:
    mid = (lo + hi + 1) // 2
    if sum(x // mid for x in f) >= n:
        lo = mid
    else:
        hi = mid - 1
print(lo)
```
