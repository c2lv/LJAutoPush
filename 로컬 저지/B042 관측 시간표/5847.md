### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n = int(data[0])
meet = sorted((int(data[2 * i + 2]), int(data[2 * i + 1])) for i in range(n))
cnt = 0
last = -1
for e, s in meet:
    if s >= last:
        cnt += 1
        last = e
print(cnt)
```
