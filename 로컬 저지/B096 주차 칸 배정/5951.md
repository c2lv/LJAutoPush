### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
m = int(data[1])
fixed = [int(v) for v in data[2:2 + m]]
f = [1, 1]
for i in range(2, 41):
    f.append(f[-1] + f[-2])
ans = 1
prev = 0
for x in fixed + [n + 1]:
    ans *= f[x - prev - 1]
    prev = x
print(ans)
```
