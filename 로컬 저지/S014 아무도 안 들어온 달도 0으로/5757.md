## 프롬프트

### 낸 코드

```
WITH RECURSIVE months AS (
    SELECT 1 AS month
    UNION ALL
    SELECT month + 1 FROM months WHERE month < 8
)
SELECT 
    m.month AS month,
    COUNT(r.id) AS cnt
FROM 
    months m
LEFT JOIN 
    registered_member r
ON 
    m.month = CAST(strftime('%m', r.datetime) AS INTEGER)
GROUP BY 
    m.month
ORDER BY 
    m.month
```
