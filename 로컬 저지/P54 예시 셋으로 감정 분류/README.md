# [P54] 예시 셋으로 감정 분류

[문제 보기](https://localjudge.com/problems/P54)

> 예시 셋으로 긍정과 부정을 가릅니다. 마지막에 둔 라벨이 기본값처럼 작동하니 순서를 신경 써보세요.

## 분류

400점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 어려움, 퓨샷 고정, 라벨 쏠림, 분류, 퓨샷 설계, 한 줄 입력, 한국어

## 문제

입출력 예시 세 쌍만으로 감정 분류를 시킵니다.

| 들어오는 리뷰 | 내야 하는 답 |
| --- | --- |
| 배터리가 생각보다 오래가서 만족합니다. | 긍정 |

이 문제에는 "둘 중 하나만 출력하라" 고 적을 프롬프트 칸이 없습니다. 제출한 예시 셋이 그대로 들어가고 그 뒤에 시험 입력이 붙는 틀이라, 어떤 리뷰를 고르고 어떤 라벨을 어느 자리에 두느냐가 전부입니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 15자 이상 23자 이하입니다.

## 출력 조건

- 첫째 줄에 `긍정`, `부정` 가운데 하나를 출력합니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 상품 리뷰 한 문장입니다.
- 출력은 `긍정` 또는 `부정` 가운데 하나입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 이 문제는 프롬프트를 쓰지 않습니다. **입출력 예시 세 쌍**만 제출합니다.
- 틀은 고정입니다. 제출한 예시 셋이 그대로 들어가고 그 뒤에 시험 입력이 붙습니다.
- 예시로 무엇을 고르느냐만으로 점수가 갈립니다. **덮지 않은 종류에서 틀립니다.**
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
배터리가 생각보다 오래가서 만족합니다.
```

기대 출력

```
긍정
```

**예시 2**

입력

```
이틀 만에 고장났고 문의해도 답이 없네요.
```

기대 출력

```
부정
```

**예시 3**

입력

```
포장도 깔끔하고 배송도 빨랐어요.
```

기대 출력

```
긍정
```

**예시 4**

입력

```
사진이랑 색이 완전히 다릅니다.
```

기대 출력

```
부정
```

**예시 5**

입력

```
가격 생각하면 이 정도면 훌륭하죠.
```

기대 출력

```
긍정
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

실측에서 가장 또렷하게 나온 사실이 이 문제의 전부입니다. **퓨샷의 마지막 답이 모델의 기본값이 됩니다.** P14 는 마지막 답이 부정이었고 틀린 9건이 전부 부정이었습니다. P35 와 P40 은 마지막이 긍정이었고 틀린 것이 전부 긍정이었습니다. 세 문제에서 세 번 다 맞았습니다.

셋 중 둘은 한쪽 라벨이 될 수밖에 없습니다. 어느 쪽을 둘로 하고, 무엇을 마지막에 둘 것인가.
