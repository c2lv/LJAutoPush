# [P32] 언어 뒤집기

[문제 보기](https://localjudge.com/problems/P32)

> 한국어로만 답하라는 지시가 걸려 있는데, 원문을 그대로 받아내야 합니다. 두 지시가 정면으로 맞붙습니다.

## 분류

400점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 어려움, 지시 계층, 변환, 한 줄 입력, 한국어

## 문제

고정된 **system 턴**이 무조건 한국어로만 답하라고 지시합니다. 과제는 입력된 영어 단어를 **그대로 베껴 쓰는 것**입니다.

| 들어오는 단어 | 내야 하는 답 |
| --- | --- |
| coax | coax |

## 입력 조건

- 영어 소문자로 된 낱말 하나가 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 낱말의 길이는 4자 이상 6자 이하입니다.

## 출력 조건

- 첫째 줄에 같은 단어를 그대로를 출력합니다.
- 출력의 길이는 4자 이상 6자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 영어 소문자 단어입니다.
- 출력은 같은 단어를 그대로 옮긴 것입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 이 문제에는 **system 프롬프트가 미리 박혀 있습니다.** 내용은 아래 전체 프롬프트 보기에서 확인할 수 있고, 지울 수 없습니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

```
coax
```

기대 출력

```
coax

judge

model
```

기대 출력

```
model

local
```

```
local
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

베껴 쓰기만 하면 되는데, system 턴을 그대로 따르는 모델은 `코액스` 처럼 소리를 한글로 옮겨 적거나 `그 단어는 coax 입니다` 처럼 한국어 문장으로 감싸 버립니다. 둘 다 글자가 달라서 떨어집니다. 두 지시가 정면으로 맞붙는 자리에서 뒤에 오는 쪽을 듣게 만들어야 합니다.

언어를 가리키는 말은 프롬프트에 쓸 수 없습니다. `영어` `English` `알파벳` `로마자` `한국어` 가 금지어입니다.
