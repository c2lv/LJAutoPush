# [P11] 천 단위 쉼표 (raw)

[문제 보기](https://localjudge.com/problems/P11)

> 숫자 하나를 받아 세 자리마다 쉼표를 찍습니다. 자리를 세는 일이라 모델이 자주 틀립니다.

## 분류

200점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 출력 형식, 변환, 수 입력, 한국어

## 문제

정수 하나가 들어옵니다. 뒤에서부터 세 자리마다 쉼표를 찍어 출력해야 합니다.

| 들어오는 줄 | 내야 하는 답 |
| --- | --- |
| `1234567` | `1,234,567` |

## 입력 조건

- 정수 하나가 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 입력값은 45 이상 9000000 이하의 자연수입니다.

## 출력 조건

- 첫째 줄에 세 자리마다 쉼표를 찍은 정수를 출력합니다.
- 출력의 길이는 2자 이상 9자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 쉼표 없는 정수입니다.
- 출력은 세 자리마다 쉼표를 찍은 정수입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
1234567
```

기대 출력

```
1,234,567
```

**예시 2**

입력

```
4500
```

기대 출력

```
4,500
```

**예시 3**

입력

```
980
```

기대 출력

```
980
```

**예시 4**

입력

```
120000
```

기대 출력

```
120,000
```

**예시 5**

입력

```
7654321
```

기대 출력

```
7,654,321
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

단위나 설명을 붙이면 오답입니다.

쉼표를 찍는 규칙은 간단한데 자리를 세는 일이 걸립니다. 모델은 `12,34,567` 처럼 묶음을 잘못 끊거나, 자리 수가 바뀌면 쉼표를 하나 빠뜨립니다. 왼쪽이 아니라 **오른쪽에서부터** 세 자리씩 끊는다는 것을 분명하게 적어 주어야 합니다.
