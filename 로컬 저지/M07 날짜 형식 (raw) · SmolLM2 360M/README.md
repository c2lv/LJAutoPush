# [M07] 날짜 형식 (raw) · SmolLM2 360M

[문제 보기](https://localjudge.com/problems/M07)

> 모델은 한 자리 수 앞에 0 을 채우는 것을 자주 잊습니다. 날짜를 YYYY-MM-DD 모양으로 바꿔보세요.

## 분류

200점, raw, smollm2-360m, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 출력 형식, 변환, 가벼운 모델, 한 줄 입력, 한국어

## 문제

`2026년 3월 7일` 형태가 들어옵니다. `YYYY-MM-DD` 로 바꿔 출력해야 합니다.

| 들어오는 문장 | 내야 하는 답 |
| --- | --- |
| 2026년 3월 7일 | 2026-03-07 |

월과 일이 한 자리면 앞에 0을 붙여야 합니다. 위 케이스를 `2026-3-7` 로 내면 떨어집니다. 작은 모델이 가장 자주 틀리는 자리입니다. 프롬프트를 어떻게 써야 이 문제가 풀리는지 고민해 보세요.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 11자 이상 13자 이하입니다.

## 출력 조건

- 첫째 줄에 `YYYY-MM-DD`를 출력합니다.
- 출력의 길이는 항상 10자입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `YYYY년 M월 D일`입니다.
- 출력은 `YYYY-MM-DD` 형태입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 이 문제는 **SmolLM2 360M** 로 풉니다. Qwen3 0.6B 보다 훨씬 작은 모델이라 같은 프롬프트가 그대로 통하지 않습니다.
- 이 모델은 영어 위주로 배워서 한국어 지시를 잘 못 알아듣습니다. **프롬프트에는 영어를 쓰셔도 됩니다.** 입력과 기대 출력만 문제가 정한 대로면 됩니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

```

```

```

```

```

```

