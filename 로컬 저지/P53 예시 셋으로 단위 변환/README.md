# [P53] 예시 셋으로 단위 변환

[문제 보기](https://localjudge.com/problems/P53)

> 프롬프트를 쓸 수 없습니다. 입출력 예시 세 쌍만 제출해서 모델이 규칙을 스스로 알아내게 만들어보세요.

## 분류

300점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 퓨샷 고정, 퓨샷 설계, 일반화, 계산, 한 줄 입력, 한국어

## 문제

이 문제는 프롬프트를 쓰지 않습니다. **입출력 예시 세 쌍**만 제출합니다. 틀은 고정이고 제출한 셋이 그대로 들어갑니다.

| 들어오는 입력 | 내야 하는 답 |
| --- | --- |
| 3 km -> m | 3000 |

모델이 보는 것은 여러분이 고른 세 쌍과 그 뒤에 붙은 시험 입력뿐입니다. 어떤 단위에 무엇을 곱하라는 설명은 한 줄도 들어가지 않습니다. 규칙을 예시만으로 짐작하게 만들어야 합니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 8자 이상 11자 이하입니다.

## 출력 조건

- 첫째 줄에 변환한 결과를 정수로 출력합니다.
- 출력값은 120 이상 11000 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `숫자 단위 -> 단위` 형태입니다.
- 출력은 변환한 결과 정수입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 이 문제는 프롬프트를 쓰지 않습니다. **입출력 예시 세 쌍**만 제출합니다.
- 틀은 고정입니다. 제출한 예시 셋이 그대로 들어가고 그 뒤에 시험 입력이 붙습니다.
- 예시로 무엇을 고르느냐만으로 점수가 갈립니다. **덮지 않은 종류에서 틀립니다.**
- 출력의 **마지막 정수**만 봅니다. 앞에 과정을 적어도 됩니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
3 km -> m
```

기대 출력

```
3000
```

**예시 2**

입력

```
5 m -> cm
```

기대 출력

```
500
```

**예시 3**

입력

```
12 cm -> mm
```

기대 출력

```
120
```

**예시 4**

입력

```
2 kg -> g
```

기대 출력

```
2000
```

**예시 5**

입력

```
7 시간 -> 분
```

기대 출력

```
420
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

실측에서 나온 교훈을 여기서 그대로 써 볼 수 있습니다. P16 은 `cm → mm` 가 예시에 없어서 모델이 100 을 곱했습니다. 10 입니다. **예시가 덮지 않은 종류에서 틀립니다.** 변환이 여러 가지 섞여 있는데 보여 줄 수 있는 것은 셋뿐입니다. 무엇을 고를지 정해보세요.
