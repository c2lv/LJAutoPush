# [P17] 단위 변환 (chat)

[문제 보기](https://localjudge.com/problems/P17)

> 마지막 정수만 읽기 때문에 조수의 수다는 어느 정도 견딥니다. 대신 계산을 틀리지 않게 만들어야 합니다.

## 분류

200점, chat, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 일반화, 퓨샷 설계, 계산, 설명 억제, 한 줄 입력, 한국어

## 문제

`3 km -> m` 처럼 단위를 바꾸라는 식이 한 줄로 들어옵니다. 바꾼 결과를 정수로 출력해야 합니다. 단위 변환 (raw) 문제와 사실상 같은 과제이고, 이 문제는 chat 모드입니다.

| 들어오는 입력 | 내야 하는 답 |
| --- | --- |
| 3 km -> m | 3000 |

어려운 쪽은 환산 배수입니다. 0.6B 는 1000 을 곱하는 자리에서 0 을 하나 빼먹는 일이 잦습니다. 배수를 모델의 기억에 맡기지 말고 프롬프트에서 짚어 주는 쪽이 안전합니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 9자 이상 11자 이하입니다.

## 출력 조건

- 첫째 줄에 변환 결과를 정수로 출력합니다.
- 출력값은 120 이상 30000 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `14 km -> m` 형태입니다.
- 출력은 변환한 결과를 정수로 적은 것입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력의 **마지막 정수**만 봅니다. 앞에 과정을 적어도 됩니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
3 km -> m
```

기대 출력

```
3000
```

**예시 2**

입력

```
5 m -> cm
```

기대 출력

```
500
```

**예시 3**

입력

```
2 kg -> g
```

기대 출력

```
2000
```

**예시 4**

입력

```
7 시간 -> 분
```

기대 출력

```
420
```

**예시 5**

입력

```
15 분 -> 초
```

기대 출력

```
900
```

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

채점이 마지막 정수만 보기 때문에 조수의 설명을 어느 정도 견딥니다. 다만 설명 끝에 다른 숫자가 오면 그게 답으로 잡힙니다.
