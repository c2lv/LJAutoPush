### 파이썬 코드

```python
def check(N):
    count = 0
    while N > 0:
        if N < 10:
            if N == 3 or N == 7:
                count += 1
        else:
            if N%10 == 3 or N%10 == 7:
                count += 1
        N = N//10
    return count

def solution(N):
    answer = 0
    for i in range(N+1):
        answer += check(i)
    return answer
```
