### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n = int(data[0])
m = int(data[1])
h = list(map(int, data[2:2 + n]))
h.sort(reverse=True)
pre = 0
ans = 0
for k in range(1, n + 1):
    pre += h[k - 1]
    if pre < m:
        continue
    H = (pre - m) // k
    if k == n or H >= h[k]:
        ans = H
        break
print(ans)
```
