### 파이썬 코드

```python
import sys

# 입력 받기
N = sys.stdin.readline().strip()

# 각 숫자의 개수를 세기 위한 리스트
digit_count = [0] * 10

# 각 숫자의 개수를 세기
for digit in N:
    digit_count[int(digit)] += 1

# 가장 큰 수를 만들기 위해 9부터 0까지 순서대로 출력
result = []
for digit in range(9, -1, -1):
    result.append(str(digit) * digit_count[digit])

# 결과를 하나의 문자열로 합치기
print(''.join(result))
```
