### 파이썬 코드

```python
def solution(N, M, K, scores):
    cnt = 0
    s = 0
    lo = 0
    for hi in range(N):
        v = scores[hi]
        if v % 2 == 1:
            s = 0
            lo = hi + 1
            continue
        s += v
        while s > M:
            s -= scores[lo]
            lo += 1
        if s == M and lo <= hi and hi - lo + 1 <= K:
            cnt += 1
    return cnt
```
