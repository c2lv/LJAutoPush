# [A022] 소수 판별

[문제 보기](https://localjudge.com/problems/A022)

> A 이상 B 이하의 모든 자연수에 대해 소수인지 아닌지 그 여부를 판별하고자 한다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 기초 수학, 소수 판별, 구현, 한국어

## 문제

A 이상 B 이하의 모든 자연수에 대해 소수인지 아닌지 그 여부를 판별하고자 한다. 이때, A는 100,000,000 이상 100,010,000 이하의 자연수이며, B는 A 이상 100,010,000 이하의 자연수이다.

결과적으로 A와 B가 주어졌을 때, A 이상 B 이하의 모든 자연수 중에서 소수의 개수를 계산하는 프로그램을 작성하여라.

예를 들어 A의 값이 100,000,005이고, B의 값이 100,000,010인 상황을 가정해 보자. 이때, A 이상 B 이하의 각 자연수에 대하여 소수인지 아닌지 여부를 표로 나타내면 다음과 같다. 소수인 경우 참(T)이며, 소수가 아닌 경우 거짓(F)으로 그 값이 기록되어 있다.

| 값 | 소수 여부 |
| --- | --- |
| 100000005 | F |
| 100000006 | F |
| 100000007 | T |
| 100000008 | F |
| 100000009 | F |
| 100000010 | F |

따라서 현재 예시에서는 A 이상 B 이하의 모든 자연수 중에서 소수의 개수(정답)가 1이다.

## 입출력 예시

## 예시 1

입력

```
100000000, 100000000
```

출력

```
0
```

## 예시 2

입력

```
100000000, 100000007
```

출력

```
1
```

## 예시 3

입력

```
100008572, 100009233
```

출력

```
31
```

## 입력 조건

- A와 B가 자연수 형태로 차례대로 주어진다. 이때, A는 100,000,000 이상 100,010,000 이하의 자연수이며, B는 A 이상 100,010,000 이하의 자연수이다.

## 출력 조건

- A 이상 B 이하의 모든 자연수 중에서 소수의 개수를 반환하여라.

## 요구사항

- solution(A, B) 함수를 만들고 답을 반환해야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 6개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
