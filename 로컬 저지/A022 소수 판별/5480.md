### 파이썬 코드

```python
def is_prime(n):
    if n < 2:
        return 0
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return 0
    return 1

def solution(A, B):
    answer = 0
    for i in range(A, B+1):
        answer += is_prime(i)
    return answer
```
