### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
k = int(data[1])
coins = sorted((int(x) for x in data[2:2 + n]), reverse=True)
cnt = 0
for c in coins:
    cnt += k // c
    k %= c
print(cnt)
```
