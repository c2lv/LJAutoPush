### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n, s = int(data[0]), int(data[1])
a = list(map(int, data[2:2 + n]))
best = n + 1
total = 0
lo = 0
for hi in range(n):
    total += a[hi]
    while total >= s:
        if hi - lo + 1 < best:
            best = hi - lo + 1
        total -= a[lo]
        lo += 1
print(0 if best == n + 1 else best)
```
