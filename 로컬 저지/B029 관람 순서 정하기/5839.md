### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n = int(data[0])
pts = sorted((int(data[2 * i + 2]), int(data[2 * i + 1])) for i in range(n))
sys.stdout.write("\n".join("%d %d" % (x, y) for y, x in pts) + "\n\n")
```
