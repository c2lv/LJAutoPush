# [M04] 대문자로 (chat) · SmolLM2 360M

[문제 보기](https://localjudge.com/problems/M04)

> 같은 일을 조수 모드로 시킵니다. 모델이 앞에 인사말을 붙이지 않게 만들어보세요.

## 분류

200점, chat, smollm2-360m, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 출력 형식, 변환, 설명 억제, 가벼운 모델, 한 줄 입력, 한국어

## 문제

대문자로 (raw) 문제와 사실상 같은 문제입니다. chat 모드 문제입니다.

영어 소문자 낱말 하나가 들어오면 같은 낱말을 대문자로 바꾸어 한 줄로 내야 합니다.

| 들어오는 낱말 | 내야 하는 답 |
| --- | --- |
| hello | HELLO |

조수는 `"HELLO"` 처럼 따옴표를 붙이거나 `대문자로 바꾸면 HELLO 입니다` 라고 설명하려 듭니다. 그 여지를 없애는 것이 과제입니다.

## 입력 조건

- 영어 소문자로 된 낱말 하나가 입력으로 들어옵니다.
- 입력은 한 줄로 들어옵니다.
- 낱말의 길이는 5자 이상 6자 이하입니다.

## 출력 조건

- 첫째 줄에 같은 단어를 대문자로 바꾸어 출력합니다.
- 출력의 길이는 5자 이상 6자 이하입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 영어 소문자 단어 하나입니다.
- 출력은 같은 단어를 대문자로 바꾼 것입니다.
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 이 문제는 **SmolLM2 360M** 로 풉니다. Qwen3 0.6B 보다 훨씬 작은 모델이라 같은 프롬프트가 그대로 통하지 않습니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

입력

```
hello
```

```

```

JUDGE
```

**예시 3**

```
token

기대 출력

```
TOKEN
```

**예시 4**

입력

```
model
```

기대 출력

```
MODEL
```

**예시 5**

입력

```
local
```

기대 출력

```
LOCAL
```
