### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
t = int(data[0])
p = [0, 1, 1, 1]
for i in range(4, 101):
    p.append(p[i - 2] + p[i - 3])
print("\n".join(str(p[int(x)]) for x in data[1:1 + t]))
```
