# [B084] 거쳐 가는 언어의 수

[문제 보기](https://localjudge.com/problems/B084)

> 사전을 갈아 쓰며 1번 언어로 쓰인 문서를 N번 언어로 옮길 때, 문서가 거치는 언어의 최소 개수를 구한다.

## 분류

300점, 케이스 15, 출제 dongbinna, 보통, 너비 우선 탐색(BFS), 최단 경로, 그래프 이론, 한국어

## 문제

어느 번역소에는 1번부터 N번까지 번호가 붙은 언어가 있고, 사전이 M권 꽂혀 있다. 사전 한 권은 언어 K개를 다룬다. 사전 한 권만 있으면 그 사전이 다루는 언어끼리는 어느 쪽에서 어느 쪽으로든 문서를 옮길 수 있다.

번역소에 1번 언어로 쓰인 문서 하나가 들어왔다. 이 문서를 N번 언어로 옮겨야 한다. 한 번 옮길 때는 사전 한 권을 고르고, 그 사전이 다루는 언어 가운데 하나를 골라 문서를 그 언어로 다시 쓴다. 고른 사전이 지금 문서가 쓰인 언어를 다루고 있지 않다면 그 사전은 쓸 수 없다. 이 작업을 몇 번이고 되풀이해 문서를 N번 언어까지 가져간다.

번역소의 담당자는 문서가 거치는 언어의 개수를 되도록 적게 하려 한다. 이때 처음의 1번 언어와 마지막의 N번 언어도 함께 센다.

결과적으로 각 사전이 다루는 언어의 정보가 주어졌을 때, 문서가 거치는 언어의 최소 개수를 구하는 프로그램을 작성하여라.

예를 들어 N=5개의 언어가 있고 K=3, M=2인 상태에서 각 사전이 다루는 언어가 다음의 표와 같다고 해보자.

| 사전 | 다루는 언어 |
| --- | --- |
| 1번 | 1번, 2번, 3번 |
| 2번 | 3번, 4번, 5번 |

1번 언어로 쓰인 문서를 1번 사전으로 3번 언어로 옮기고, 이어서 2번 사전으로 5번 언어로 옮기면 된다. 3번 언어는 두 사전이 함께 다루고 있으므로 1번 사전에서 2번 사전으로 갈아 쓰는 발판이 된다. 이 과정을 차례대로 적으면 다음과 같다.

| 차례 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 문서의 언어 | 1번 | 3번 | 5번 |
| 쓴 사전 |  | 1번 | 2번 |

문서가 거친 언어는 1번, 3번, 5번이라 모두 3개다. 2번 언어나 4번 언어를 지나가는 길도 있지만 그렇게 하면 거치는 언어가 늘어난다. 따라서 이 경우 정답은 3이다.

한편 어느 사전에도 실려 있지 않은 언어가 있을 수 있다. 1번 언어에서 출발해 N번 언어까지 갈 길이 아예 없다면 -1을 출력한다.

## 입출력 예시

## 예시 1

입력

```
5 3 2
1 2 3
3 4 5
```

출력

```
3
```

## 예시 2

입력

```
10 4 3
10 1 9 8
1 3 6 8
2 3 5 10
```

출력

```
2
```

## 예시 3

입력

```
3 2 2
2 1
1 2
```

출력

```
-1
```

## 입력 조건

- 가장 먼저 언어의 수 N과 사전 한 권이 다루는 언어의 수 K, 그리고 사전의 수 M이 공백으로 구분되어 한 줄에 주어진다. N은 100,000보다 작거나 같은 자연수이며, K와 M은 각각 1,000보다 작거나 같은 자연수다.
- 이어서 M개의 줄에 걸쳐 1번 사전부터 M번 사전까지 각 사전이 다루는 언어의 번호가 공백으로 구분되어 차례대로 주어진다. 언어의 번호는 1 이상 N 이하의 자연수이며, 한 줄에 적히는 번호의 개수는 K개를 넘지 않는다. 입력에 적히는 언어 번호의 총 개수는 1,000,000개를 넘지 않는다.

## 출력 조건

- 문서가 거치는 언어의 최소 개수를 한 줄에 출력한다. 처음의 1번 언어와 마지막의 N번 언어도 함께 센 값이다. 1번 언어에서 N번 언어로 갈 길이 없다면 -1을 출력한다. 수 하나만 출력하므로 줄 끝에 남기는 공백은 없다.

## 요구사항

- 한 사전이 다루는 언어끼리는 한 번의 작업으로 서로 옮길 수 있습니다
- 답은 문서가 거친 언어의 개수이므로, 처음의 1번 언어와 마지막의 N번 언어도 함께 셉니다
- N이 1이면 처음 언어와 마지막 언어가 같으므로 답은 1입니다
- N번 언어로 갈 길이 없다면 -1을 출력합니다
- 언어와 사전을 모두 하나의 점으로 보고 이어 붙이면 점의 개수가 최대 101,000개가 됩니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
