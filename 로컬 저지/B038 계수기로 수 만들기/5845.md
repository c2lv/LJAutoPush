### 파이썬 코드

```python
import sys

a, b = map(int, sys.stdin.read().split()[:2])
cnt = 1
while b > a:
    if b % 2 == 0:
        b //= 2
    elif b % 10 == 1:
        b //= 10
    else:
        break
    cnt += 1
print(cnt if b == a else -1)
```
