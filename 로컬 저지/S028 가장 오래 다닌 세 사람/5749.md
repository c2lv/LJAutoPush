## 프롬프트

### 낸 코드

```
SELECT r.name, r.grade
FROM registered_member r
JOIN retired_member m ON r.id = m.id
ORDER BY julianday(m.datetime) - julianday(r.datetime) DESC, r.name ASC
LIMIT 3
```
