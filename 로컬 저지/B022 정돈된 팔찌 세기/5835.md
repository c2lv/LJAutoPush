### 파이썬 코드

```python
import sys

data = sys.stdin.read().split()
n = int(data[0])
cnt = 0
for w in data[1:1 + n]:
    seen = set()
    prev = ""
    ok = True
    for ch in w:
        if ch != prev:
            if ch in seen:
                ok = False
                break
            seen.add(ch)
            prev = ch
    if ok:
        cnt += 1
print(cnt)
```
