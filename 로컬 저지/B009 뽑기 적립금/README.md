# [B009] 뽑기 적립금

[문제 보기](https://localjudge.com/problems/B009)

> 뽑기 기계에서 굴러 나온 공 세 개에 적힌 수로 손님이 받는 적립금을 계산한다.

## 분류

200점, 케이스 15, 출제 dongbinna, 쉬움, 기초 문법, 조건문, 한국어

## 문제

한 문구점 앞에는 뽑기 기계가 놓여 있다. 한 번 뽑으면 공 세 개가 차례대로 굴러 나오고, 각 공에는 1부터 6까지의 수 가운데 하나가 적혀 있다. 서로 다른 공에 같은 수가 적혀 있을 수도 있다.

문구점 주인은 굴러 나온 세 수를 보고 손님에게 적립금을 준다. 적립금의 기준은 다음의 표와 같다.

| 경우 | 적립금 |
| --- | --- |
| 세 수가 모두 같을 때 | 10,000 + (같은 수) × 1,000원 |
| 두 수만 같을 때 | 1,000 + (같은 수) × 100원 |
| 세 수가 모두 다를 때 | (가장 큰 수) × 100원 |

두 수만 같은 경우에는 어느 두 공의 수가 같은지 따져야 한다. 첫째와 둘째가 같을 수도 있고, 첫째와 셋째가 같을 수도 있고, 둘째와 셋째가 같을 수도 있다. 세 경우 모두 같은 수를 찾아 기준에 넣어야 한다.

공 세 개에 적힌 수가 주어졌을 때, 손님이 받는 적립금을 출력하는 프로그램을 작성하여라.

예를 들어 공에 적힌 수가 차례대로 3, 3, 6이라고 해보자. 어느 경우에 해당하는지 따져 나가는 중간 과정은 다음의 표와 같다.

| 단계 | 내용 |
| --- | --- |
| 공에 적힌 수 | 3, 3, 6 |
| 세 수가 모두 같은지 | 아니다 |
| 두 수만 같은지 | 그렇다. 첫째와 둘째가 3으로 같다 |
| 쓰는 기준 | 1,000 + (같은 수) × 100원 |
| 적립금 | 1300 |

따라서 이 경우의 적립금은 1,300원이다.

다른 뽑기의 결과까지 함께 표로 정리하면 다음과 같다.

| 공에 적힌 수 | 3, 3, 6 | 2, 2, 2 | 1, 2, 3 | 5, 1, 5 | 2, 6, 6 |
| --- | --- | --- | --- | --- | --- |
| 해당하는 경우 | 두 수만 같을 때 | 세 수가 모두 같을 때 | 모두 다를 때 | 두 수만 같을 때 | 두 수만 같을 때 |
| 적립금 | 1300 | 12000 | 300 | 1500 | 1600 |

5, 1, 5는 첫째와 셋째가 같고, 2, 6, 6은 둘째와 셋째가 같은 경우다.

## 입출력 예시

## 예시 1

입력

```
3 3 6
```

출력

```
1300
```

## 예시 2

입력

```
2 2 2
```

출력

```
12000
```

## 예시 3

입력

```
1 2 3
```

출력

```
300
```

## 입력 조건

- 가장 먼저 첫째 줄에 공 세 개에 적힌 수가 공백 하나로 구분되어 차례대로 주어진다. 각 수는 1 이상 6 이하의 정수다. 세 수는 공이 굴러 나온 순서대로 주어지며, 서로 같은 수가 섞여 있을 수도 있다. 세 수가 모두 같은 경우, 두 수만 같은 경우, 모두 다른 경우가 모두 들어올 수 있고 순서를 정렬해 주지는 않는다. 입력으로 주어지는 줄은 이 한 줄뿐이며, 수 사이의 공백은 하나다.

## 출력 조건

- 손님이 받는 적립금을 첫째 줄에 자연수 형태로 출력한다. 원 단위는 적지 않고 수만 찍으며, 천 단위 쉼표도 찍지 않는다. 1,300원이라면 1300 으로 찍는다. 수 하나만 찍고 줄을 바꾸며, 수 뒤에 공백을 붙이지 않는다.

## 요구사항

- 입력은 한 줄이고, 세 수가 공백 하나로 구분되어 주어집니다
- 각 수는 1 이상 6 이하의 정수입니다
- 두 수만 같은 경우에는 어느 두 공이 같은지 모두 따져야 합니다
- 적립금은 단위와 천 단위 쉼표 없이 수만 찍습니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
