### 파이썬 코드

```python
import sys

n = int(sys.stdin.read().split()[0])
MOD = 1000000000
dp = [0] + [1] * 9
for _ in range(n - 1):
    nd = [0] * 10
    for d in range(10):
        if d > 0:
            nd[d] += dp[d - 1]
        if d < 9:
            nd[d] += dp[d + 1]
        nd[d] %= MOD
    dp = nd
print(sum(dp) % MOD)
```
