# [P09] JSON으로 묶기 (raw)

[문제 보기](https://localjudge.com/problems/P09)

> JSON 은 한 글자만 어긋나도 읽히지 않는 형식입니다. 공백도 코드블록도 없이, 키 순서까지 맞춰서 만들어보세요.

## 분류

300점, raw, qwen3-0.6b, 케이스 16, 최대 16토큰, 출제 dongbinna, 보통, 출력 형식, 구조화 출력, 한 줄 입력, 한국어

## 문제

`이름: 김철수, 나이: 30` 형태가 들어옵니다. 아래 형태로 정확히 출력해야 합니다.

```
{"name":"김철수","age":30}
```

| 들어오는 입력 | 내야 하는 답 |
| --- | --- |
| 이름: 김철수, 나이: 30 | {"name":"김철수","age":30} |

하는 일은 이름과 나이를 `name` 과 `age` 자리로 옮겨 담는 것뿐입니다. 다만 JSON 은 한 글자만 어긋나도 못 읽는 형식입니다. 받는 쪽 프로그램이 바로 읽을 수 있는 모양으로 나와야 합니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 항상 15자입니다.

## 출력 조건

- 첫째 줄에 압축 JSON 한 줄을 출력합니다.
- 출력의 길이는 항상 23자입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `이름: 홍길동, 나이: 25`입니다.
- 출력은 공백을 뺀 JSON 한 줄입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
이름: 김철수, 나이: 30
```

기대 출력

```
{"name":"김철수","age":30}
```

**예시 2**

입력

```
이름: 박영희, 나이: 27
```

기대 출력

```
{"name":"박영희","age":27}
```

**예시 3**

입력

```
이름: 이준호, 나이: 41
```

기대 출력

```
{"name":"이준호","age":41}
```

**예시 4**

입력

```
이름: 최민서, 나이: 19
```

기대 출력

```
{"name":"최민서","age":19}
```

**예시 5**

입력

```
이름: 정다은, 나이: 35
```

기대 출력

```
{"name":"정다은","age":35}
```

## 참고 사항

풀이에 도움이 되는 배경입니다. 지켜야 하는 규격은 위의 입출력 조건과 요구사항에 있습니다.

콜론과 쉼표 뒤에 공백이 없어야 합니다. 백틱 코드블록을 붙이면 오답입니다. 나이는 따옴표 없는 숫자입니다. 키 순서는 name 다음 age.
