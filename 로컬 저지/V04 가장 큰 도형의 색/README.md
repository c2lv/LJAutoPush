# [V04] 가장 큰 도형의 색

[문제 보기](https://localjudge.com/problems/V04)

> 크기가 다른 동그라미 넷 중 가장 큰 것의 색을 영어 소문자로 출력하게 만드세요.

## 분류

300점, chat, smolvlm-500m, 케이스 16, 최대 12토큰, 출제 dongbinna, 보통, 그림 읽기, 견주기, 그림 입력, 한국어

## 문제

그림에 크기가 다른 동그라미가 넷 있다. 그중 **가장 큰 것**의 색을 영어 소문자 한 낱말로 출력하라.

가장 큰 것은 나머지보다 뚜렷하게 크다. 눈으로 헷갈릴 일은 없다.

| 그림에 보이는 것 | 내야 하는 답 |
| --- | --- |
| 색이 서로 다른 작은 동그라미 셋과 뚜렷하게 큰 빨강 동그라미 하나 | `red` |

V02 와 닮았지만 하나가 더 얹혀 있다. 색을 보는 것에 더해 **크기를 견주어야** 한다. 재 보니 맞힌 것은 16번 중 13번이었고 글자 그대로는 0이었다.

그 0 이 나오는 자리는 둘이다. 하나는 가장 큰 것이 아니라 눈에 먼저 들어온 색을 내는 것이고, 다른 하나는 색은 맞게 보고도 `red` 대신 `Red` 나 `빨강` 혹은 `The largest circle is red` 로 적는 것이다.

이 문제의 입력은 글이 아니라 **그림**이다. 케이스마다 그림 한 장이 모델에 들어가고, 여러분이 쓴 글은 그 그림과 **같은 차례**에 들어간다. 그림을 말로 설명할 필요는 없다. 모델이 이미 보고 있다.

## 입력 조건

- 크기가 다른 동그라미 넷이 그려진 그림
- 입력은 한 줄로 들어옵니다.

## 출력 조건

- red / blue / green / yellow / purple 중 하나. 소문자로
- 출력은 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 최대 12 토큰
- 케이스는 16개
- 가장 큰 것의 색입니다. 가장 많은 색이 아닙니다
- **chat 모드**입니다. 채팅 템플릿으로 감싸 모델이 조수가 됩니다. 제어 토큰을 직접 적어 여러 턴짜리 대화를 만들 수 있습니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 앞뒤 공백만 무시합니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 12 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
red
```

기대 출력

```
blue
```

**예시 2**

입력

```
green
```

기대 출력

```
yellow
```

**예시 3**

입력

```
purple
```
