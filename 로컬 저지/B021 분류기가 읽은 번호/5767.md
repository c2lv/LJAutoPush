### 파이썬 코드

```python
import sys

# 입력 받기
input = sys.stdin.read().split()

# 번호 추출
num1 = input[0]
num2 = input[1]

# 번호를 거꾸로 읽기
reversed_num1 = num1[::-1]
reversed_num2 = num2[::-1]

# 거꾸로 읽은 번호를 정수로 변환
num1_value = int(reversed_num1)
num2_value = int(reversed_num2)

# 더 큰 값을 출력
if num1_value > num2_value:
    print(num1_value)
else:
    print(num2_value)
```
