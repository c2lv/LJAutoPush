# [B021] 분류기가 읽은 번호

[문제 보기](https://localjudge.com/problems/B021)

> 세 자리 번호를 끝 자리부터 거꾸로 읽는 분류기가 두 상자 가운데 더 큰 번호를 고른다.

## 분류

100점, 케이스 15, 출제 dongbinna, 아주 쉬움, 기초 문법, 문자열, 구현, 한국어

## 문제

한 물류 창고의 분류기는 상자에 적힌 세 자리 번호를 읽어서 상자를 보낼 곳을 정한다. 그런데 이 분류기는 번호를 왼쪽에서 오른쪽으로 읽지 않는다. 번호의 맨 끝 자리부터 거꾸로 읽어서 하나의 수로 받아들인다.

예를 들어 상자에 734가 적혀 있다고 해보자. 분류기는 끝 자리인 4를 가장 먼저 읽고, 그다음에 가운데 자리인 3을 읽고, 마지막으로 첫 자리인 7을 읽는다.

| 읽는 순서 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 읽은 자릿값 | 4 | 3 | 7 |

그래서 분류기는 734를 437로 받아들인다.

지금 분류기 앞에 상자 두 개가 놓여 있다. 창고 직원은 분류기가 읽은 두 수 가운데 더 큰 쪽을 먼저 보내려고 한다. 두 상자에 적힌 번호가 주어질 때, 분류기가 읽은 두 수 가운데 더 큰 값을 출력하는 프로그램을 작성하여라.

예를 들어 두 상자에 적힌 번호가 차례대로 734와 893이라고 해보자. 이때 분류기는 두 번호를 다음의 표와 같이 읽는다.

| 상자 | 1번 | 2번 |
| --- | --- | --- |
| 적힌 번호 | 734 | 893 |
| 분류기가 읽은 번호 | 437 | 398 |

분류기가 읽은 두 수는 437과 398이다. 437이 더 크므로 이 경우 정답은 437이다. 적힌 번호만 보면 893이 734보다 크지만, 분류기가 읽은 값의 순서는 그 반대가 된다.

반대로 적힌 번호의 순서와 읽은 번호의 순서가 그대로 유지되는 경우도 있다. 두 상자에 적힌 번호가 차례대로 954와 359라고 해보자.

| 상자 | 1번 | 2번 |
| --- | --- | --- |
| 적힌 번호 | 954 | 359 |
| 분류기가 읽은 번호 | 459 | 953 |

이 경우 분류기가 읽은 두 수는 459와 953이므로 정답은 953이다. 그러므로 적힌 번호끼리 견주지 말고, 거꾸로 읽은 두 수를 견주어야 한다.

두 상자에 같은 번호가 적혀 있는 경우도 있다. 이때는 분류기가 읽은 두 수도 서로 같으므로, 그 값을 그대로 출력한다. 또한 번호에는 0이 들어 있지 않으므로, 거꾸로 읽은 수가 0으로 시작하는 경우는 생각하지 않아도 된다.

## 입출력 예시

## 예시 1

입력

```
734 893
```

출력

```
437
```

## 예시 2

입력

```
954 359
```

출력

```
953
```

## 예시 3

입력

```
111 111
```

출력

```
111
```

## 입력 조건

- 가장 먼저 첫째 줄에 두 상자에 적힌 번호가 공백 하나로 구분되어 차례대로 주어진다. 두 번호는 모두 세 자리 자연수이므로 100 이상 999 이하의 값을 가진다. 또한 각 자릿값은 1 이상 9 이하이므로 번호에 0은 들어 있지 않다. 두 상자에 같은 번호가 적혀 있을 수도 있다.

## 출력 조건

- 분류기가 읽은 두 수 가운데 더 큰 값을 한 줄에 출력한다. 값 뒤에 공백을 따로 붙이지 않으며, 줄을 한 번 바꾸고 끝낸다.

## 요구사항

- 입력은 표준 입력으로 받고, 결과는 표준 출력으로 내보냅니다
- 번호는 맨 끝 자리부터 거꾸로 읽습니다
- 두 번호가 같으면 분류기가 읽은 두 수도 같으므로 그 값을 그대로 출력합니다
- 값 하나만 한 줄에 출력합니다
- 표준 입력으로 읽고 표준 출력으로 내보내는 프로그램을 짜야 합니다
- 쓸 수 있는 말은 파이썬, 자바스크립트입니다
- 메모리 제한은 256MB입니다. 브라우저에서는 재지 않고 적기만 합니다
- 시간 제한은 출제자의 정답 코드를 같은 런타임에서 재서 정합니다
- 이 문제는 프롬프트가 아니라 **코드**를 냅니다. 그 코드는 **이 기기의 브라우저에서** 돌고, 서버로는 나온 출력의 지문과 걸린 시간만 갑니다. 맞았는지는 **서버가** 정합니다. 실행 시간은 각자 기기가 적어 보내는 값이라, 코드와 기기 정보를 순위표에 **같이 내걸어** 둡니다.
- 출력이 **글자 하나까지** 기대값과 같아야 합니다. 줄 안의 빈칸은 다른 글자와 똑같이 봅니다.
- 케이스는 15개이고, 그 가운데 3개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 제출할 때만 쓰이고 화면에는 보여 주지 않습니다.
- 케이스 15개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 채점 과정을 건드려 통과한 것처럼 꾸미는 경우 적발 시 제재될 수 있습니다. 제출한 코드는 순위표에 함께 공개됩니다.
