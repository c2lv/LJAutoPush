# [M16] 단위 변환 (raw) · SmolLM2 360M

[문제 보기](https://localjudge.com/problems/M16)

> 곱셈 자체는 쉬운데 출력 형식이 어렵습니다. 채점은 마지막 정수만 읽으니 그 점을 이용해보세요.

## 분류

200점, raw, smollm2-360m, 케이스 16, 최대 16토큰, 출제 dongbinna, 쉬움, 일반화, 퓨샷 설계, 계산, 가벼운 모델, 한 줄 입력, 한국어

## 문제

`값 단위 -> 목표단위` 형태가 들어옵니다. 변환한 값을 정수로 출력해야 합니다.

| 들어오는 줄 | 내야 하는 답 |
| --- | --- |
| `3 km -> m` | `3000` |

배수가 정수인 변환만 나옵니다. 채점은 출력의 **마지막 정수**만 보므로 과정을 적어도 됩니다. 과정을 먼저 적고 마지막에 `3000` 이 오면 통과합니다.

걸리는 자리는 두 곳입니다. 하나는 배수를 틀리는 것입니다. 다른 하나는 답을 적고 나서 수를 하나 더 적는 것입니다. `3000 m 는 3 km 입니다` 처럼 이어 쓰면 뒤에 온 `3` 이 답으로 잡힙니다.

## 입력 조건

- 입력은 한 줄로 들어옵니다.
- 입력의 길이는 9자 이상 11자 이하입니다.

## 출력 조건

- 첫째 줄에 변환 결과를 정수로 출력합니다.
- 출력값은 120 이상 30000 이하의 자연수입니다.
- 다른 글자는 붙이지 않습니다.
- 기대값과 한 글자도 달라서는 안 됩니다.

## 요구사항

- 입력은 `14 km -> m` 형태입니다.
- 출력은 변환한 결과를 정수로 적은 것입니다.
- **raw 모드**입니다. 두 조각과 입력을 그대로 이어붙여 모델에 넣습니다. 채팅 템플릿도 `<think>` 도 붙지 않습니다. 채점은 첫 줄까지만 봅니다.
- 출력의 **마지막 정수**만 봅니다. 앞에 과정을 적어도 됩니다.
- 이 문제는 **SmolLM2 360M** 로 풉니다. Qwen3 0.6B 보다 훨씬 작은 모델이라 같은 프롬프트가 그대로 통하지 않습니다.
- 이 모델은 영어 위주로 배워서 한국어 지시를 잘 못 알아듣습니다. **프롬프트에는 영어를 쓰셔도 됩니다.** 입력과 기대 출력만 문제가 정한 대로면 됩니다.
- 케이스는 16개이고, 그 가운데 5개는 입력과 기대 출력을 함께 보여 줍니다. 나머지는 입력만 보여 줍니다.
- 모델 출력은 최대 16 토큰까지만 받습니다.
- 케이스 16개를 **전부** 통과해야 해결입니다.

> 문제의 요구 사항을 잘 읽고 해결해 주세요. 단, 프롬프트 인젝션 등을 활용해 높은 점수를 받도록 조작하는 경우 적발 시 제재될 수 있습니다.

## 예시

공개 케이스 5개입니다. 채점에는 숨은 케이스가 함께 쓰입니다. 케이스 16개를 전부 통과해야 해결입니다.

**예시 1**

입력

```
3 km -> m
```

기대 출력

```
3000
```

**예시 2**

입력

```
5 m -> cm
```

기대 출력

```
500
```

**예시 3**

입력

```
2 kg -> g
```

기대 출력

```
2000
```

**예시 4**

입력

```
7 시간 -> 분
```

기대 출력

```
420
```

**예시 5**

입력

```
15 분 -> 초
```

기대 출력

```
900
```
