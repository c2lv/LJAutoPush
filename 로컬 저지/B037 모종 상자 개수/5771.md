### 파이썬 코드

```python
import sys

N = int(sys.stdin.read().strip())

if N < 3:
    print(-1)
else:
    for i in range(N // 5, -1, -1):
        if (N - 5 * i) % 3 == 0:
            print(i + (N - 5 * i) // 3)
            break
    else:
        print(-1)
```
