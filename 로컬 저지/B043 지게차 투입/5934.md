### 파이썬 코드

```python
import sys

data = sys.stdin.buffer.read().split()
n = int(data[0])
wait = [0] * 1000002
cnt = 0
for v in map(int, data[1:1 + n]):
    if wait[v]:
        wait[v] -= 1
    else:
        cnt += 1
    wait[v - 1] += 1
print(cnt)
```
